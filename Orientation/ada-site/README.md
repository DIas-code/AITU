# ada-site

Учебный сайт по магистратуре **Applied Data Analytics (7M06103)**, Astana IT University.
Сейчас покрывает подготовку к первому триместру: математика для науки о данных и
программирование для анализа данных и баз данных.

Сайт двуязычный: английский основной, русский равноценный. На выходе — обычные
статические HTML-страницы, никакого рантайма.

## Запуск

```bash
npm install      # один раз
npm run dev      # http://localhost:4321
npm run build    # соберёт dist/
npm run preview  # посмотреть собранное
npm run check    # проверка типов, должно быть 0 errors
```

## Что где лежит

```
src/
├── data/            ← ВСЁ СОДЕРЖИМОЕ ЗДЕСЬ. Правишь только эту папку.
│   ├── types.ts       типы. L10n = { en, ru } — любая видимая строка
│   ├── courses.ts     дисциплины: паспорт, оценивание, пререквизиты, чек-лист
│   ├── plan.ts        недели 1–10 и неделя разминки
│   ├── books.ts       каталог литературы с главами
│   ├── calendar.ts    академический календарь, даты триместров
│   ├── resources.ts   стек, установка, ресурсы, датасеты, метод
│   └── ui.ts          строки интерфейса
├── pages/
│   ├── index.astro          редирект на /en.html
│   └── [lang]/              страницы обоих языков генерируются из одного файла
│       ├── index.astro      обзор
│       ├── plan.astro       план 11 недель
│       ├── books.astro      литература с картой глав
│       ├── kit.astro        инструменты
│       └── courses/[slug].astro   страница на каждую дисциплину
├── components/      переиспользуемые куски разметки
├── layouts/Base.astro   шапка, меню, переключатель языка, тема
├── lib/             даты и построение ссылок
└── styles/global.css    все стили и токены тем
```

Страницы генерируются перемножением языков и данных: `[lang]/courses/[slug].astro`
даёт `/en/courses/math.html`, `/ru/courses/math.html` и так далее.

## Как дополнять

**Добавить дисциплину.** Скопируй объект в `src/data/courses.ts`, поменяй `slug`.
Появятся две страницы и два пункта меню. Ничего больше править не нужно.

**Получил силлабус — уточнить темы.** `src/data/plan.ts`, массив `WEEKS`. Разбивка тем
там сейчас — реконструкция по содержанию курса из хендбука, а не календарно-тематический
план. Правь `title`, `detail` и `reading`.

**Добавить книгу или главы.** `src/data/books.ts`. Пропиши главы в `chapters`, потом
ссылайся из недели: `reading: [{ book: "mckinney", chapters: [5, 6] }]`.
Страница «Литература» сама покажет, на какой неделе какая глава нужна.

**Добавить триместр.** Допиши объект в `TERMS` в `src/data/calendar.ts`, поставь
`trimester: 2` у новых дисциплин. Дальше по мере надобности — отдельная страница
триместра по образцу `plan.astro`.

**Поменять вид.** Все цвета и шрифты — токены в начале `src/styles/global.css`,
светлая и тёмная темы описаны рядом.

## Публикация

Собранный `dist/` — статика, кладётся куда угодно. Для GitHub Pages раскомментируй
`site` и `base` в `astro.config.mjs`, иначе абсолютные ссылки не найдут страницы.

## Источники и что здесь не официальное

Официальные данные взяты из трёх документов AITU, которые лежат в родительской папке:

| Документ | Что взято |
| --- | --- |
| `УП ADA.pdf` | кредиты, часы, коды, циклы, форма контроля |
| `ADA_MS_Module Handbook_2025.pdf` | преподаватели, язык, схема оценивания, содержание, литература |
| `Академ календарь 2026-2027_1 курс_ADA_МАГ.pdf` | все даты, недели, контрольные точки |

**Реконструкция, а не документ университета:** разбивка тем по неделям, привязка глав к
неделям, план разминки, еженедельные задания, чек-листы самопроверки, подборка ресурсов
и структура репозитория. Номера глав указаны по изданию, названному в `books.ts`, —
в другом издании ищи главу по названию.

На первой неделе возьми силлабусы у преподавателей и поправь `plan.ts`.
