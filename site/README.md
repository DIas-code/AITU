# Материалы курсов

Сайт с лекциями и практиками по неделям. Курс → 10 недель → материалы недели.
Статический: на выходе обычные HTML-файлы, никакого сервера не нужно.

## Запуск

```bash
npm install        # один раз
npm run dev        # http://localhost:4321 — с автообновлением
npm run build      # собрать в dist/
npm run preview    # посмотреть собранное
npm run check      # проверка типов
```

`npm run build` сам вызывает `npm run prep` — вынимает картинки из ноутбуков и копирует
исходники в `public/`.

## Где что лежит

```
src/data/courses.ts            курсы: название, часы, преподаватель, путь к папке с материалами
src/data/plan.ts               план из силлабуса: темы 10 недель, оценивание, литература
src/data/lessons.ts            список всех материалов
src/data/lessons/<курс>/       сами лекции: w01-l1.ts, w01-l2.ts …
src/data/types.ts              модель данных: Lesson, Section, Block
src/pages/                     страницы
src/components/                блоки: код, картинка, выноска, текст RU/EN
public/data/<курс>/<wNN>/      файлы данных к примерам (plants.txt и т.п.)
public/media/, public/source/  генерируются скриптами, в git не хранятся
```

Материалы читаются из папки курса рядом с проектом — см. `sourceDir` в `courses.ts`:

```
Aitu/
  Programing for data analysis/     ← sourceDir курса prog
    eng_Syllabus_...docx            ← силлабус, попадёт в «Документы» на странице курса
    week1/                          ← папка недели
      Lecture_1_2025.ipynb
      ...
  site/                             ← этот проект
```

## Как добавить материалы

1. Положи `.ipynb` в папку недели: `<папка курса>/week2/`. Папку создай, если её нет —
   называется строго `week` + номер.
2. Скажи Claude: «добавь лекцию из week2 на сайт». Он прочитает ноутбук, перепишет текст
   связно, прогонит код, сверит вывод и создаст `src/data/lessons/<курс>/w02-l1.ts`.
3. Новый файл нужно импортировать в `src/data/lessons.ts` и добавить в массив `LESSONS` —
   дальше страница, плитка недели и меню появятся сами.

Сайт — не выгрузка ноутбука, а переписанный материал. Код и его вывод берутся из оригинала
без изменений; если в ноутбуке ячейки не выполнены, код прогоняется и в лекцию попадает
настоящий вывод.

## Как добавить курс

Скопируй объект в `COURSES` (`src/data/courses.ts`), поменяй `slug`, `sourceDir` и остальные
поля. Добавь план недель в `WEEK_PLAN` (`src/data/plan.ts`). Страница `/courses/<slug>.html`
и пункт меню появятся сами.

## Публикация

Папку `dist/` можно открыть локально или выложить на любой хостинг. Для GitHub Pages
раскомментируй `site` и `base` в `astro.config.mjs`.
