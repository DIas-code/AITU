Decimal()math2 раза в коде лекций

Что это. Десятичное число с контролируемой точностью.

Зачем. Стандарт для денег: у float 1.10 + 2.20 даёт 3.3000000000000003, у Decimal — ровно 3.30. Создавать нужно из строки, не из float.

Пример
