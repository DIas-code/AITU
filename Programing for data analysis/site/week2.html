nums = [1, 2, 3]
print(nums.pop())    # → 3
print(nums)          # → [1, 2]

student = {"name": "Aida", "temp": 1}
student.pop("temp")
print(student)       # → {'name': 'Aida'}
Как это было в лекции
student.pop("active", None)
