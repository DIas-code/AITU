# Сайт магистратуры ADA · AITU

Личный учебный сайт по первому триместру: все четыре курса, конспекты лекций, сроки и дедлайны из Moodle — в одном месте.

**Как открыть:** двойной щелчок по `Website/index.html`. Сервер не нужен, интернет нужен только для формул (MathJax) и подсветки кода.

---

## Что есть на сайте

### Главная — `index.html`
- **Ближайшие сроки** — всё, что наступает в ближайшие 14 дней, по всем курсам, с пометкой «сегодня / завтра / через N дней». Плюс еженедельные дела (SIS по английскому, reflective note по педагогике).
- **Курсы** — четыре карточки: тема текущей недели и следующий срок.
- **Календарь** — midterm, endterm, сессия, каникулы (из академического календаря).
- **Сроки по неделям** — таблица 10 недель × 4 курса.
- **Ориентация** — ссылки на документы программы (календарь, учебный план, handbook).

### Дедлайны — `deadlines.html`
Всё, что стоит в твоём календаре Moodle, кроме расписания пар (Attendance).
- **По неделям** — неделя с понедельника по воскресенье, стрелками листаешь недели.
- **По предметам** — все дедлайны курса, сгруппированные по неделям.
- Фильтр по курсу, клик по дедлайну раскрывает описание из Moodle.

### Страница курса — `<курс>/course.html`
Недели 1–10: тема по силлабусу, страницы-конспекты, файлы недели (pdf, pptx), сроки. Внизу — формула оценки, важные правила и ссылка на силлабус.

### Конспекты
| Курс | Что есть |
|---|---|
| Mathematics for Data Science | Недели 1–3: **формулы** (карточка = что это / где / как / пример) и **лекция**. Калькуляторы, таблицы t, F, χ². Русский и английский — кнопка EN/RU. |
| Programming for Data Analysis and Database | 13 страниц — по одной на каждый ноутбук недель 1–3. Только код, который использовался, и объяснение: что, зачем, как. |
| Foreign Language (Professional) C1 | Пока страница курса и ссылки на готовые материалы (слайды SDG 7, помощник для эссе). |
| Pedagogy of Higher Education | Пока страница курса. |

На каждой странице урока внизу — «← Назад / Дальше →» и ссылка на исходный файл (ноутбук).

## Как всё устроено

```
Aitu/
├── Website/                          ← ВЕСЬ САЙТ
│   ├── index.html                    главная
│   ├── deadlines.html                дедлайны из Moodle
│   ├── README.md                     этот файл
│   ├── _shared/                      общее для всех страниц
│   │   ├── sitemap.js                КАРТА САЙТА: курсы, недели, страницы, сроки
│   │   ├── site.css                  оформление
│   │   ├── site.js                   шапка, меню недель, «назад / дальше», подсветка кода
│   │   ├── data.js                   даты недель, «через N дней»
│   │   ├── course.js                 рисует страницу курса из карты сайта
│   │   ├── moodle.js                 читает календарь Moodle
│   │   └── moodle-snapshot.js        сохранённая копия календаря (не в git)
│   ├── Mathematics for Data Science/
│   │   ├── course.html
│   │   ├── week1/ week2/ week3/      formulas.html, lecture.html
│   │   └── reference/                калькуляторы и таблицы
│   ├── Programming for Data Analysis and Database/
│   │   ├── course.html
│   │   └── week1/ week2/ week3/      страница на каждый ноутбук
│   ├── Foreign Language (Professional) C1/course.html
│   └── Pedagogy of Higher Education/course.html
│
├── Math/, Programing for data analysis/, Prof english/, pedagogy/
│                                     ← твои исходные материалы (pdf, pptx, ipynb, задания)
├── Orientation/                      документы программы
├── Syllabi/                          силлабусы (только на компьютере, не в git)
├── api/ics.js, vercel.json           для онлайн-версии на Vercel
└── Dias Calendar/                    мини-сервер, который берёт календарь из Moodle
```

**Сайт и материалы разделены.** В `Website/` лежат только страницы сайта. Лекции, задания и силлабусы остаются в папках курсов, сайт на них ссылается — ничего не копируется.

**Одна карта сайта.** Всё, что показывает сайт — курсы, темы недель, список страниц, сроки, файлы, — записано в одном файле `_shared/sitemap.js`. Главная, страницы курсов, меню и кнопки «назад / дальше» строятся из него. Поэтому новая страница или новый срок — это правка в одном месте, и они сразу появляются везде.

**Никакой автоматики.** Нет сборщиков и генераторов: каждая страница — обычный HTML-файл. Изменения вношу я, когда ты просишь.

### Откуда сроки
- **Из Moodle** — точная дата и время, помечены «· Moodle». Moodle важнее силлабуса.
- **Из силлабуса** — если в Moodle задания ещё нет. Помечены «≈ … · по силлабусу»: это суббота той недели, на которую задание стоит в силлабусе.
- Сдано задание или нет — **сайт не отслеживает**, сроки — это напоминания.

### Как работает страница «Дедлайны»
1. Если запущен `Dias Calendar` — страница берёт календарь прямо из Moodle, вверху «Живые данные из Moodle». Кнопка «↻ Обновить» скачивает заново.
2. Если не запущен — показывает сохранённую копию календаря и её дату.

Запустить `Dias Calendar`: открыть терминал в папке `Aitu/Dias Calendar` → `npm run dev` → оставить окно открытым. Остановить — `Ctrl + C`.
Ссылка на твой календарь Moodle хранится только в `Dias Calendar/.env.local` и в git не попадает.

## Онлайн-версия (Vercel)

Сайт можно открыть откуда угодно после выкладки на Vercel (весь репозиторий `DIas-code/AITU`):
- главный адрес сразу ведёт на `/Website/` (`vercel.json`);
- дедлайны онлайн берутся функцией `api/ics.js` — ссылка на календарь Moodle хранится в настройках Vercel (`MOODLE_CALENDAR_URL`), в коде её нет; Dias Calendar онлайн не нужен;
- после каждого `git push` Vercel сам выкладывает новую версию;
- **силлабусы онлайн не выкладываются** — они лежат в `Aitu/Syllabi/` и в git не попадают.

## Как что-то поменять

Просто скажи мне:
- «добавь лекцию из week4 по Programming» — прочитаю ноутбук, сделаю страницу, добавлю в меню;
- «добавь формулы 4-й недели по Math»;
- «обнови дедлайны» — скачаю свежий календарь Moodle, сверю сроки на сайте;
- «появился Assignment 3, срок такой-то» — внесу в сроки.

Правила, по которым я делаю страницы, записаны в `Aitu/CLAUDE.md`.
