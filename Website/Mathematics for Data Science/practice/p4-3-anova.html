Задача 3. Снижение холестерина

group_A = [12, 14, 13, 11, 15], group_B = [15, 16, 14, 17, 13], group_C = [18, 20, 19, 21, 17]. α = 0,05.

H₀:μA = μB = μC — препараты одинаково эффективныH₁:хотя бы один препарат отличается

Шаг 1. Средние

\[ \bar{x}_A=\frac{65}{5}=13\,,\quad \bar{x}_B=\frac{75}{5}=15\,,\quad \bar{x}_C=\frac{95}{5}=19\,,\qquad \bar{x}=\frac{235}{15}=15{,}667 \]

Шаг 2. SSW

A: отклонения −1, 1, 0, −2, 2 → 1+1+0+4+4 = 10. B: 0, 1, −1, 2, −2 → 10. C: −1, 1, 0, 2, −2 → 10.

\[ SS_W=10+10+10=30 \]

Шаг 3. SSB

\[ SS_B=5(13-15{,}667)^2+5(15-15{,}667)^2+5(19-15{,}667)^2=35{,}56+2{,}22+55{,}56=93{,}33 \]

Шаг 4. Таблица ANOVA

ИсточникSSdfMSF
Между93,33246,6746,67 / 2,5 = 18,67
Внутри30122,5
Общее123,3314
\[ F=18{,}67\,,\qquad F_{\text{кр}}(0{,}05;\,2;\,12)=3{,}89 \]

Вывод: 18,67 > 3,89 → H₀ отвергаем. Препараты различаются по эффективности (C снижает сильнее всех).

То же в Python

from scipy import stats

group_A = [12, 14, 13, 11, 15]
group_B = [15, 16, 14, 17, 13]
group_C = [18, 20, 19, 21, 17]

F, p = stats.f_oneway(group_A, group_B, group_C)   # one-way ANOVA
print(round(F, 3), round(p, 5))                    # → 18.667 0.00021
print(round(stats.f.ppf(0.95, 2, 12), 3))          # F_кр → 3.885

p = 0,00021 < 0,05 → H₀ отвергаем — тот же вывод, что и через Fкр.
