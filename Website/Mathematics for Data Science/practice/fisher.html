Как решать F-критерий Фишера

  1. F сравнивает дисперсии (разброс), а не средние. Средние для F не нужны.
  2. H₀: дисперсии равны (различие случайно). H₁: дисперсии различаются.
  3. Бо́льшую дисперсию — в числитель, поэтому F ≥ 1. Если дано σ — сначала возвести в квадрат.
  4. k₁ = n − 1 той группы, что в числителе; k₂ = n − 1 той, что в знаменателе.
  5. Fкр — таблица Фишера α = 0,05: столбец k₁, строка k₂. Если нужного столбца нет — берём между соседними.
  6. F < Fкр → H₀ принимаем; F > Fкр → H₀ отвергаем.
\[ F=\frac{S_1^2}{S_2^2}\quad (S_1^2>S_2^2)\,,\qquad k_1=n_1-1\,,\quad k_2=n_2-1 \]

Зачем ещё нужен F: перед t-критерием для независимых выборок проверяют, что дисперсии групп равны. Ниже это сделано для задач Практики 1 и Assignment 1.

Assignment 1, Part II

Задача 1. Изменчивость высоты пшеницы

После кукурузы: x̄₁ = 108 см, n₁ = 15, S₁² = 25 см². После гороха: x̄₂ = 111 см, n₂ = 12, S₂² = 16 см². Различаются ли растения по изменчивости высоты или различие дисперсий случайно? α = 0,05.

Шаг 1. Какой критерий

Сравниваем разброс (дисперсии) двух групп → F-критерий Фишера. Средние 108 и 111 здесь не используются.

Шаг 2. Гипотезы

H₀:σ₁² = σ₂² — изменчивость одинаковая, различие дисперсий случайноH₁:σ₁² ≠ σ₂² — изменчивость действительно различается

Шаг 3. Формула

\[ F=\frac{S^2_{\text{больш}}}{S^2_{\text{меньш}}}\,,\qquad k_1=n_{\text{больш}}-1\,,\quad k_2=n_{\text{меньш}}-1 \]

Шаг 4. Дано

  • после кукурузы: S² = 25, n = 15
  • после гороха: S² = 16, n = 12
  • α = 0,05

Шаг 5. Какая дисперсия больше

25 > 16 → в числитель идёт после кукурузы, в знаменатель после гороха.

Шаг 6. F

\[ F=\frac{25}{16}=1{,}5625 \]

Шаг 7. Степени свободы

\[ k_1=15-1=14\ (\text{числитель})\,,\qquad k_2=12-1=11\ (\text{знаменатель}) \]

Шаг 8. Критическое значение

Таблица Фишера, α = 0,05: столбец k₁ = 14, строка k₂ = 11:

\[ F_{\text{кр}}=2{,}74 \]

Шаг 9. Сравнение и вывод

F = 1,5625 < Fкр = 2,74 → H₀ принимаем.
Вывод: различие дисперсий случайное, несущественное — по изменчивости высоты растения не различаются. (В таблице нет столбца 14: между k₁ = 12 → 2,79 и k₁ = 24 → 2,61.)

Задача 2. Разброс веса на двух диетах

Диета A: n = 28, дисперсия 25. Диета B: n = 26, дисперсия 10. Отличаются ли результаты по разбросу? α = 0,05.

Шаг 1. Какой критерий

Сравниваем разброс (дисперсии) двух групп → F-критерий Фишера.

Шаг 2. Гипотезы

H₀:σ₁² = σ₂² — разброс одинаковыйH₁:σ₁² ≠ σ₂² — разброс различается

Шаг 3. Формула

\[ F=\frac{S^2_{\text{больш}}}{S^2_{\text{меньш}}}\,,\qquad k_1=n_{\text{больш}}-1\,,\quad k_2=n_{\text{меньш}}-1 \]

Шаг 4. Дано

  • диета A: S² = 25, n = 28
  • диета B: S² = 10, n = 26
  • α = 0,05

Шаг 5. Какая дисперсия больше

25 > 10 → в числитель идёт диета A, в знаменатель диета B.

Шаг 6. F

\[ F=\frac{25}{10}=2{,}5 \]

Шаг 7. Степени свободы

\[ k_1=28-1=27\ (\text{числитель})\,,\qquad k_2=26-1=25\ (\text{знаменатель}) \]

Шаг 8. Критическое значение

Таблица Фишера, α = 0,05: столбец k₁ = 27, строка k₂ = 25:

\[ F_{\text{кр}}=1{,}94 \]

Шаг 9. Сравнение и вывод

F = 2,5 > Fкр = 1,94 → H₀ отвергаем, принимаем H₁.
Вывод: на диете A разброс веса значимо больше. (В таблице строка 25: k₁ = 24 → 1,96, ∞ → 1,71; F = 2,5 больше обоих.)

Практика 1, задача 2. Два университета

s₁ = 10, n₁ = 20; s₂ = 12, n₂ = 22. Равны ли дисперсии?

Шаг 1. Какой критерий

Сравниваем разброс (дисперсии) двух групп → F-критерий Фишера. Даны σ → S² = σ²: 10² = 100, 12² = 144.

Шаг 2. Гипотезы

H₀:σ₁² = σ₂² — разброс баллов одинаковыйH₁:σ₁² ≠ σ₂² — разброс различается

Шаг 3. Формула

\[ F=\frac{S^2_{\text{больш}}}{S^2_{\text{меньш}}}\,,\qquad k_1=n_{\text{больш}}-1\,,\quad k_2=n_{\text{меньш}}-1 \]

Шаг 4. Дано

  • ун-т 2: S² = 144, n = 22
  • ун-т 1: S² = 100, n = 20
  • α = 0,05

Шаг 5. Какая дисперсия больше

144 > 100 → в числитель идёт ун-т 2, в знаменатель ун-т 1.

Шаг 6. F

\[ F=\frac{144}{100}=1{,}44 \]

Шаг 7. Степени свободы

\[ k_1=22-1=21\ (\text{числитель})\,,\qquad k_2=20-1=19\ (\text{знаменатель}) \]

Шаг 8. Критическое значение

Таблица Фишера, α = 0,05: столбец k₁ = 21, строка k₂ = 19:

\[ F_{\text{кр}}=2{,}14 \]

Шаг 9. Сравнение и вывод

F = 1,44 < Fкр = 2,14 → H₀ принимаем.
Вывод: дисперсии равны — t-критерий применять можно.
