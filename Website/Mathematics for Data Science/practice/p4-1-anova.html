Алгоритм one-way ANOVA (лекция 4)

H₀:μ₁ = μ₂ = … = μk — все средние равныH₁:хотя бы одно среднее отличается (не «все не равны»!)
  1. Средние групп x̄j и общее среднее x̄ (сумма всех / N).
  2. SSW — внутри групп: каждое значение минус среднее своей группы, в квадрат, сложить.
  3. SSB — между группами: nj·(x̄j − x̄)², сложить по группам.
  4. dfB = k − 1, dfW = N − k. MS = SS / df. F = MSB / MSW.
  5. F > Fкр(α; dfB; dfW) → H₀ отвергаем.
\[ SS_B=\sum_j n_j(\bar{x}_j-\bar{x})^2\,,\qquad SS_W=\sum_j\sum_i (x_{ij}-\bar{x}_j)^2\,,\qquad SS_T=SS_B+SS_W \] \[ MS_B=\frac{SS_B}{k-1}\,,\qquad MS_W=\frac{SS_W}{N-k}\,,\qquad F=\frac{MS_B}{MS_W} \]

Почему не t-критерий попарно: при множественных сравнениях растёт вероятность ошибки 1-го рода. ANOVA говорит только «есть различие», но не какая группа отличается.
