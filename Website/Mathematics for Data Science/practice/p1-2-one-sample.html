Формула для всех задач страницы

H₀:μ = μ₀ — среднее равно нормеH₁:μ ≠ μ₀ — отличается
\[ t=\frac{\bar{x}-\mu_0}{s/\sqrt{n}}\,,\qquad df=n-1\,,\qquad |t|>t_{\text{кр}}\ \Rightarrow\ H_0 \text{ отвергаем} \]

Где α не указан, берём α = 0,05.

Задача 1. Рост студентов

x̄ = 174 см, s = 8, n = 25. Средний рост равен 170 см? α = 0,05.

H₀:μ = 170H₁:μ ≠ 170
\[ \frac{s}{\sqrt{n}}=\frac{8}{\sqrt{25}}=\frac{8}{5}=1{,}6\,,\qquad t=\frac{174-170}{1{,}6}=2{,}5 \] \[ df=24\,,\qquad t_{\text{кр}}(0{,}05;\,24)=2{,}064 \]

Вывод: 2,5 > 2,064 → H₀ отвергаем. Средний рост значимо отличается от 170 см.

Задача 3. Гемоглобин

n = 15, x̄ = 132 г/л, s = 9 г/л. Отличается ли от нормы 130 г/л? α = 0,05.

H₀:μ = 130H₁:μ ≠ 130
\[ \frac{9}{\sqrt{15}}=\frac{9}{3{,}873}=2{,}324\,,\qquad t=\frac{132-130}{2{,}324}=0{,}861 \] \[ df=14\,,\qquad t_{\text{кр}}(0{,}05;\,14)=2{,}145 \]

Вывод: 0,861 < 2,145 → H₀ принимаем. Уровень гемоглобина от нормы не отличается.

Задача 4. Удовлетворённость студентов

x̄ = 3,8, s = 0,6, n = 25. Средний балл равен 4,0?

H₀:μ = 4,0H₁:μ ≠ 4,0
\[ \frac{0{,}6}{\sqrt{25}}=0{,}12\,,\qquad t=\frac{3{,}8-4{,}0}{0{,}12}=-1{,}667\,,\qquad |t|=1{,}667 \] \[ df=24\,,\qquad t_{\text{кр}}(0{,}05;\,24)=2{,}064 \]

Вывод: 1,667 < 2,064 → H₀ принимаем. Средний балл не отличается от 4,0 значимо.

Задача 5. Сахар в крови

n = 12, x̄ = 5,9 ммоль/л, s = 0,4. Отличается ли от нормы 5,5?

H₀:μ = 5,5H₁:μ ≠ 5,5
\[ \frac{0{,}4}{\sqrt{12}}=\frac{0{,}4}{3{,}464}=0{,}1155\,,\qquad t=\frac{5{,}9-5{,}5}{0{,}1155}=3{,}464 \] \[ df=11\,,\qquad t_{\text{кр}}(0{,}05;\,11)=2{,}201 \]

Вывод: 3,464 > 2,201 → H₀ отвергаем. Уровень сахара значимо выше нормы.
