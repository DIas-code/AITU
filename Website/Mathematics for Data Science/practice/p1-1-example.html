Алгоритм и разобранный пример

Курение и агрегация эритроцитов — зависимые выборки, α = 0,01

Алгоритм (из практики)

  1. Сформулировать гипотезы H₀ и H₁, выбрать α.
  2. Посчитать эмпирическое t по нужной формуле.
  3. Найти степени свободы: одна выборка или зависимые — df = n − 1; независимые — df = n₁ + n₂ − 2.
  4. Найти tкр по таблице Стьюдента (двусторонний критерий).
  5. Сравнить: |tэмп| < tкр → принимаем H₀; иначе принимаем H₁.

Три формулы

\[ \text{одна выборка: } t=\frac{\bar{x}-\mu_0}{s/\sqrt{n}} \qquad \text{зависимые: } t=\frac{\bar{d}}{S_d},\ S_d=\sqrt{\frac{\sum d^2-\frac{(\sum d)^2}{n}}{n(n-1)}} \qquad \text{независимые: } t=\left|\frac{\bar{X}-\bar{Y}}{\sqrt{\frac{S_X^2}{n_1}+\frac{S_Y^2}{n_2}}}\right| \]

Решение

\[ \bar{d}=\frac{30}{10}=3\,,\qquad S_d=\sqrt{\frac{172-\frac{30^2}{10}}{10\cdot 9}}=\sqrt{\frac{172-90}{90}}=\sqrt{0{,}911}=0{,}955 \] \[ t_{\text{эмп}}=\frac{3}{0{,}955}=3{,}14\,,\qquad df=10-1=9\,,\qquad t_{\text{кр}}(0{,}01;\,9)=3{,}25 \]

Вывод: 3,14 < 3,25 → H₀ принимаем. При α = 0,01 влияние сигареты на агрегацию эритроцитов несущественно.

Заметь: при α = 0,05 tкр = 2,262, и тогда 3,14 > 2,262 — влияние было бы значимым. Уровень α важен.
