Формула для всех задач страницы

H₀:μ₁ = μ₂ — средние не различаютсяH₁:μ₁ ≠ μ₂ — различаются
\[ t=\left|\frac{\bar{X}-\bar{Y}}{S_d}\right|\,,\qquad S_d=\sqrt{\frac{S_X^2}{n_1}+\frac{S_Y^2}{n_2}}\,,\qquad df=n_1+n_2-2 \]

Дано σ → в формулу идёт σ². α = 0,05.

Задача 2. Средний балл в двух университетах

Ун-т 1: n₁ = 20, x̄₁ = 72, s₁ = 10. Ун-т 2: n₂ = 22, x̄₂ = 68, s₂ = 12. Есть ли различие в уровне знаний?

H₀:уровень знаний одинаковый, μ₁ = μ₂H₁:μ₁ ≠ μ₂
\[ S_d=\sqrt{\frac{10^2}{20}+\frac{12^2}{22}}=\sqrt{5+6{,}545}=\sqrt{11{,}545}=3{,}398 \] \[ t=\frac{72-68}{3{,}398}=1{,}177\,,\qquad df=20+22-2=40\,,\qquad t_{\text{кр}}=2{,}021 \]

Вывод: 1,177 < 2,021 → H₀ принимаем. Различие в уровне знаний незначимо.

Задача 6. Стресс у мужчин и женщин

Мужчины: 18, σ = 4, n = 20. Женщины: 20, σ = 5, n = 22.

H₀:уровень стресса одинаковыйH₁:уровень стресса различается
\[ S_d=\sqrt{\frac{4^2}{20}+\frac{5^2}{22}}=\sqrt{0{,}8+1{,}136}=\sqrt{1{,}936}=1{,}391 \] \[ t=\left|\frac{18-20}{1{,}391}\right|=1{,}437\,,\qquad df=40\,,\qquad t_{\text{кр}}=2{,}021 \]

Вывод: 1,437 < 2,021 → H₀ принимаем. Различия в стрессе нет.

Задача 7. Холестерин в двух группах

Группа 1: 6,2, σ = 0,5, n = 12. Группа 2: 5,8, σ = 0,6, n = 14.

H₀:средний холестерин одинаковыйH₁:различается
\[ S_d=\sqrt{\frac{0{,}5^2}{12}+\frac{0{,}6^2}{14}}=\sqrt{0{,}0208+0{,}0257}=\sqrt{0{,}0465}=0{,}2157 \] \[ t=\frac{6{,}2-5{,}8}{0{,}2157}=1{,}854\,,\qquad df=12+14-2=24\,,\qquad t_{\text{кр}}=2{,}064 \]

Вывод: 1,854 < 2,064 → H₀ принимаем. Различия несущественны.

Задача 9. Успеваемость до и после курса

12 студентов. До: среднее 65, σ = 5. После: среднее 70, σ = 6. Значимо ли улучшение?

Это «до/после», но пар значений нет — даны только средние и σ. Поэтому считаем по формуле для двух выборок (n₁ = n₂ = 12).

H₀:курс не изменил успеваемостьH₁:успеваемость изменилась
\[ S_d=\sqrt{\frac{5^2}{12}+\frac{6^2}{12}}=\sqrt{2{,}083+3}=\sqrt{5{,}083}=2{,}255 \] \[ t=\left|\frac{65-70}{2{,}255}\right|=2{,}218\,,\qquad df=12+12-2=22\,,\qquad t_{\text{кр}}=2{,}074 \]

Вывод: 2,218 > 2,074 → H₀ отвергаем. Улучшение значимо.
