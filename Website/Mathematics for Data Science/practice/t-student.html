Как решать t-критерий

  1. Понять тип: одна выборка (сравниваем с нормой), независимые (две разные группы), зависимые (одни и те же люди до/после).
  2. Записать H₀ (различия нет) и H₁ (различие есть).
  3. Посчитать tэмп по формуле своего типа.
  4. Степени свободы: одна выборка и зависимые — df = n − 1; независимые — df = n₁ + n₂ − 2.
  5. tкр — из таблицы Стьюдента (двусторонний) по α и df.
  6. |tэмп| < tкр → H₀ принимаем; |tэмп| > tкр → H₀ отвергаем.
\[ \text{одна выборка: } t=\frac{\bar{x}-\mu_0}{s/\sqrt{n}} \] \[ \text{независимые: } t=\left|\frac{\bar{X}-\bar{Y}}{S_d}\right|,\ S_d=\sqrt{\frac{S_X^2}{n_1}+\frac{S_Y^2}{n_2}} \] \[ \text{зависимые: } t=\frac{\bar{d}}{S_d},\ S_d=\sqrt{\frac{\sum d^2-\frac{(\sum d)^2}{n}}{n(n-1)}} \]

Если α в задаче не указан — берём α = 0,05. Если дано σ — в формулу идёт σ².

1. Одна выборка

Практика 1, задача 1. Рост студентов

x̄ = 174 см, s = 8, n = 25. Проверить гипотезу, что средний рост равен 170 см, α = 0,05.

Шаг 1. Какой критерий

Одна выборка: дано среднее, стандартное отклонение и число-норма, с которым сравниваем → t-критерий для одной выборки.

Шаг 2. Гипотезы

H₀:μ = 170 — средний рост равен 170 смH₁:μ ≠ 170 — средний рост не равен 170 см

Шаг 3. Формула

\[ t=\frac{\bar{x}-\mu_0}{s/\sqrt{n}}\,,\qquad df=n-1 \]

Шаг 4. Дано

  • x̄ = 174
  • μ₀ = 170
  • s = 8
  • n = 25
  • α = 0,05

Шаг 5. Считаем по шагам

\[ \sqrt{n}=\sqrt{25}=5 \] \[ \frac{s}{\sqrt{n}}=\frac{8}{5}=1{,}6 \] \[ \bar{x}-\mu_0=174-170=4 \] \[ t=\frac{4}{1{,}6}=2{,}5\,,\qquad |t|=2{,}5 \]

Шаг 6. Степени свободы

\[ df=n-1=25-1=24 \]

Шаг 7. Критическое значение

Таблица Стьюдента, двусторонний критерий, α = 0,05, df = 24:

\[ t_{\text{кр}}=2{,}064 \]

Шаг 8. Сравнение и вывод

|t| = 2,5 > tкр = 2,064 → H₀ отвергаем, принимаем H₁.
Вывод: средний рост значимо отличается от 170 см.

Практика 1, задача 2. Баллы в двух университетах

Ун-т 1: 20 студентов, x̄₁ = 72, s₁ = 10. Ун-т 2: 22 студента, x̄₂ = 68, s₂ = 12. Есть ли различие в уровне знаний?

Шаг 1. Какой критерий

Две разные группы людей, сравниваем средние → t-критерий для независимых выборок.

Шаг 2. Гипотезы

H₀:μ₁ = μ₂ — уровень знаний одинаковыйH₁:μ₁ ≠ μ₂ — уровень знаний различается

Шаг 3. Формула

\[ t=\left|\frac{\bar{X}-\bar{Y}}{S_d}\right|\,,\qquad S_d=\sqrt{\frac{S_X^2}{n_1}+\frac{S_Y^2}{n_2}}\,,\qquad df=n_1+n_2-2 \]

Шаг 4. Дано

  • Группа 1: x̄₁ = 72, s₁ = 10, n₁ = 20
  • Группа 2: x̄₂ = 68, s₂ = 12, n₂ = 22
  • α = 0,05

Шаг 5. Считаем по шагам

\[ S_X^2=10^2=100\,,\qquad S_Y^2=12^2=144 \] \[ \frac{S_X^2}{n_1}=\frac{100}{20}=5\,,\qquad \frac{S_Y^2}{n_2}=\frac{144}{22}=6{,}5455 \] \[ S_d=\sqrt{5+6{,}5455}=\sqrt{11{,}5455}=3{,}3979 \] \[ \bar{X}-\bar{Y}=72-68=4 \] \[ t=\left|\frac{4}{3{,}3979}\right|=1{,}177 \]

Шаг 6. Степени свободы

\[ df=n_1+n_2-2=20+22-2=40 \]

Шаг 7. Критическое значение

Таблица Стьюдента, двусторонний, α = 0,05, df = 40:

\[ t_{\text{кр}}=2{,}021 \]

Шаг 8. Сравнение и вывод

t = 1,177 < tкр = 2,021 → H₀ принимаем.
Вывод: различие в уровне знаний незначимо — уровень одинаковый.

Практика 1, задача 9. Успеваемость до и после курса

12 студентов. До курса: среднее 65, σ = 5. После: среднее 70, σ = 6. Значимо ли улучшение?

Две разные группы людей, сравниваем средние → t-критерий для независимых выборок. Это «до/после», но пар значений нет — только средние и σ, поэтому считаем по формуле для двух выборок, n₁ = n₂ = 12.

Шаг 2. Гипотезы

\[ t=\left|\frac{\bar{X}-\bar{Y}}{S_d}\right|\,,\qquad S_d=\sqrt{\frac{S_X^2}{n_1}+\frac{S_Y^2}{n_2}}\,,\qquad df=n_1+n_2-2 \]

  • Группа 1: x̄₁ = 65, s₁ = 5, n₁ = 12
  • Группа 2: x̄₂ = 70, s₂ = 6, n₂ = 12
  • α = 0,05

\[ df=n_1+n_2-2=12+12-2=22 \]

Шаг 7. Критическое значение

\[ t_{\text{кр}}=2{,}074 \]

Шаг 8. Сравнение и вывод

t = 2,218 > tкр = 2,074 → H₀ отвергаем, принимаем H₁.
Вывод: улучшение значимо.
