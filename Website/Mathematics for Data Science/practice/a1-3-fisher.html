Assignment 1 · 3/3 · F-критерий Фишера

Part II: сравнение дисперсий

Различается ли разброс (изменчивость) в двух группах

Задача 1. ПшеницаЗадача 2. Диеты

Как решать

H₀:σ₁² = σ₂² — дисперсии равны, различие случайноH₁:σ₁² ≠ σ₂² — разброс действительно различается
\[ F=\frac{S_{\text{больш}}^2}{S_{\text{меньш}}^2}\,,\qquad k_1=n_{\text{больш}}-1\ (\text{числитель})\,,\qquad k_2=n_{\text{меньш}}-1\ (\text{знаменатель}) \]
  1. Бо́льшую дисперсию — в числитель (F ≥ 1).
  2. k₁ и k₂ — по объёму той выборки, чья дисперсия стоит в числителе / знаменателе.
  3. Fкр — из таблицы Фишера α = 0,05: столбец k₁, строка k₂.
  4. F < Fкр → H₀ принимаем; F > Fкр → H₀ отвергаем.

Средние (108 и 111 см в задаче 1) для F-критерия не нужны — сравниваем только дисперсии.

Задача 1. Высота пшеницы на разных предшественниках

После кукурузы: n₁ = 15, S₁² = 25 см². После гороха: n₂ = 12, S₂² = 16 см². Различается ли изменчивость высоты? α = 0,05.

H₀:изменчивость одинаковая, различие дисперсий случайноH₁:изменчивость различается
\[ F=\frac{25}{16}=1{,}56\,,\qquad k_1=15-1=14\,,\qquad k_2=12-1=11 \] \[ F_{\text{кр}}(0{,}05;\,14;\,11)=2{,}74 \]

Вывод: 1,56 < 2,74 → H₀ принимаем. Различие дисперсий случайное, несущественное — по изменчивости высоты растения не различаются.

В таблице нет столбца 14: между k₁ = 12 (2,79) и k₁ = 24 (2,61) в строке 11; точное значение 2,74.

Задача 2. Разброс веса на двух диетах

Диета A: n = 28, дисперсия 25. Диета B: n = 26, дисперсия 10. Отличаются ли результаты по разбросу? α = 0,05.

H₀:разброс веса на диетах одинаковыйH₁:разброс различается
\[ F=\frac{25}{10}=2{,}5\,,\qquad k_1=28-1=27\,,\qquad k_2=26-1=25 \] \[ F_{\text{кр}}(0{,}05;\,27;\,25)=1{,}94 \]

Вывод: 2,5 > 1,94 → H₀ отвергаем. На диете A разброс веса значимо больше.

По таблице: строка 25, между k₁ = 24 (1,96) и ∞ (1,71) → около 1,94. F = 2,5 больше любого из них.
