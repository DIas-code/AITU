Plotly: анимация, иерархии, многомерные данные

Графики, которых нет в Matplotlib «из коробки»: кадры по годам, вложенные круги и прямоугольники, параллельные координаты, выпадающее меню. Все графики ниже живые.

Сначала слова: что как называется

fig, trace, layout, hover — на предыдущей странице. Здесь добавляются:

Кадр анимации (frame)Отдельная версия графика для одного значения. Кадры сменяют друг друга по ▶ или ползунку.кадр на каждый курс 1–4
MultiIndexИндекс из двух уровней сразу — у строки два «адреса».(year=1, program="Data Science")
reindexПодогнать таблицу под заданный список строк: недостающие добавить (с fill_value), лишние убрать.нет строки → 0
ИерархияВложенные уровни: внутри программы — курсы, внутри курса — стипендия. path задаёт порядок уровней.program → year → scholarship
Многомерные данныеУ каждого объекта много числовых признаков сразу. Обычный график показывает 2, специальные — 5 и больше.5 оценок у студента
graph_objects (go)Ручная сборка графика по кусочкам: сам добавляешь trace и настраиваешь меню. Дольше, но гибче, чем px.go.Figure(); fig.add_trace(...)
visibleПоказывать trace или нет. Выпадающее меню просто меняет, какие trace видны.[True, False, False, False]

1. Анимация по курсу обучения

Сначала считаем студентов по (курс, программа). Если в каком-то курсе программы нет, строки не будет и столбик «прыгнет» — поэтому MultiIndex.from_product строит все пары, а reindex(..., fill_value=0) дописывает недостающие нулями. animation_frame="year" — один кадр на курс, внизу ползунок и ▶. range_y фиксирует ось, чтобы она не менялась между кадрами.

animation_data = (df_clean
    .groupby(["year", "program"], as_index=False)
    .agg(students=("student_id", "count")))

programs = sorted(df_clean["program"].unique())
years = sorted(df_clean["year"].unique())
complete_index = pd.MultiIndex.from_product([years, programs], names=["year", "program"])

animation_data = (animation_data
    .set_index(["year", "program"])
    .reindex(complete_index, fill_value=0)
    .reset_index())

fig = px.bar(animation_data, x="program", y="students", color="program",
             animation_frame="year",
             range_y=[0, animation_data["students"].max() * 1.15],
             title="Student Distribution by Year of Study")
fig.update_layout(showlegend=False)
fig.update_xaxes(categoryorder="array", categoryarray=programs)
fig.show()

fig.write_html("Student_Visualization.html")

3. Sunburst и Treemap — иерархия

path — уровни вложенности сверху вниз: программа → курс → стипендия. Plotly сам считает, сколько строк в каждой ветке. Sunburst — кольца, Treemap — вложенные прямоугольники, площадь = количество. Кликни на сектор — провалишься внутрь, клик в центр — назад.

fig = px.sunburst(df_clean, path=["program", "year", "scholarship"],
                  title="Student Distribution by Program, Year and Scholarship")
fig.show()

fig = px.treemap(df_clean, path=["program", "year", "gender"],
                 title="Student Distribution by Program, Year and Gender")
fig.show()

4. Violin со всеми точками

Violin = boxplot + форма плотности. box=True — ящик внутри, points="all" — каждый студент точкой рядом.

fig = px.violin(df_clean, x="program", y="final_score", color="program",
                box=True, points="all",
                title="Final Score Distribution by Program")
fig.show()

5. Параллельные координаты

Каждая линия — один студент, каждая вертикальная ось — признак. Цвет — итоговый балл. Протяни мышью по оси (например, по final_score сверху) — останутся только эти студенты, и видно, какие у них остальные баллы.

fig = px.parallel_coordinates(
    df_clean,
    dimensions=["math_score", "programming_score", "english_score",
                "attendance", "final_score"],
    color="final_score", color_continuous_scale="Viridis",
    title="Multidimensional Student Performance Analysis")
fig.show()

6. Scatter Matrix

Scatter для каждой пары выбранных признаков — быстро увидеть, что с чем связано. diagonal_visible=False убирает бесполезную диагональ «признак сам с собой». Выдели область на одном графике — эти же точки подсветятся на остальных.

fig = px.scatter_matrix(df_clean,
    dimensions=["math_score", "programming_score", "attendance", "final_score"],
    color="program", title="Scatter Matrix of Student Performance")
fig.update_traces(diagonal_visible=False)
fig.show()

7. Выпадающее меню (graph_objects)

Добавляем 4 набора столбиков (по одному на показатель), видим только первый: visible=(i == 0). Кнопка меню передаёт список visible, где True только у выбранного. Код выполнять заново не нужно — переключает сам график. Меню — в левом верхнем углу графика.

metrics = ["math_score", "programming_score", "english_score", "final_score"]
fig = go.Figure()

for i, metric in enumerate(metrics):
    avg = df_clean.groupby("program")[metric].mean()
    fig.add_trace(go.Bar(x=avg.index, y=avg.values, name=metric, visible=(i == 0)))

fig.update_layout(
    title="Average Student Scores by Program",
    updatemenus=[dict(
        buttons=[dict(label=metric, method="update",
                      args=[{"visible": [j == i for j in range(len(metrics))]}])
                 for i, metric in enumerate(metrics)],
        direction="down")])
fig.show()
