Группировка, сводные таблицы, корреляция

Таблица University Students 2026 New.csv: 200 студентов, 4 программы. Вопрос: у какой программы баллы выше и что сильнее всего связано с итоговой оценкой.

Сначала слова: что как называется

ГруппировкаРазложить строки по «кучкам» с одинаковым значением признака и считать отдельно в каждой.4 кучки — по программам
АгрегацияСвернуть много чисел в одно: среднее, сумма, количество, минимум… Функция-агрегат — та, что это делает.54 балла → среднее 80.41
Split → Apply → CombineРазделить на группы → посчитать в каждой → собрать ответы в одну таблицу. Так работает groupby.groupby → mean → результат
agg()Посчитать несколько агрегатов за раз или разные для разных столбцов.agg(["mean", "max"])
Сводная таблица (pivot table)Таблица «строки × столбцы → число в клетке»: одна категория по строкам, другая — по столбцам. Как в Excel.программа × курс → средний балл
КорреляцияНасколько два числа меняются вместе. От −1 до 1: близко к 1 — растут вместе, к −1 — одно растёт, другое падает, около 0 — связи нет.programming и final: 0.68
Корреляция ≠ причинаЕсли два признака связаны, это не значит, что один вызывает другой. Может быть третья причина или совпадение.посещаемость ↔ балл

1. Split → Apply → Combine

groupby("program") только делит строки на группы — сам по себе ничего не считает. Считать начинает функция после него: взяли столбец, применили mean() к каждой группе, собрали в один результат.

import pandas as pd
df_clean = pd.read_csv("University Students 2026 New.csv")

df_clean.groupby("program")                       # объект группировки, ещё без расчёта
df_clean.groupby("program")["final_score"].mean()
# Cybersecurity 79.06 · Data Science 80.41 · IT Management 78.59 · Software Engineering 80.03

2. count() или size()

count() считает непустые значения выбранного столбца, size() — все строки группы. Здесь пропусков в student_id нет, поэтому числа совпадают. Разница появится, если в столбце есть NaN.

df_clean.groupby("program")["student_id"].count()
df_clean.groupby("program").size()
# оба: Cybersecurity 47 · Data Science 54 · IT Management 37 · Software Engineering 62

df_clean.groupby("program")["final_score"].min()      # также .max(), .median()

3. Несколько столбцов и agg()

Список столбцов в [[...]] — одна функция для всех. agg([...]) — много функций за раз. agg({...}) — своя функция для каждого столбца.

df_clean.groupby("program")[
    ["math_score", "programming_score", "english_score", "final_score"]
].mean()

df_clean.groupby("program")["final_score"].agg(
    ["count", "mean", "median", "min", "max", "std"]
)
# IT Management: count 37, mean 78.59, std 9.10 — самый большой разброс

df_clean.groupby("program").agg({
    "student_id": "count",
    "admission_score": "mean",
    "attendance": "mean",
    "final_score": ["mean", "min", "max"]
})

4. Группировка по двум признакам и сортировка

Список ключей → группа на каждую пару значений (программа × пол, программа × курс). as_index=False оставляет program обычным столбцом — тогда по результату удобно сортировать.

df_clean.groupby(["program", "gender"])["final_score"].mean()
df_clean.groupby(["program", "year"])["final_score"].mean()

df_clean.groupby("program", as_index=False)["final_score"].mean() \
        .sort_values("final_score", ascending=False)
# Data Science 80.41 → Software Engineering 80.03 → Cybersecurity 79.06 → IT Management 78.59

df_clean.groupby(["program", "scholarship"]).size()   # сколько со стипендией в каждой программе
# Data Science: No 30, Yes 24

5. pivot_table — сводная таблица как в Excel

То же, что groupby по двум ключам, но второй ключ разворачивается в столбцы: строки — программы, столбцы — курс, в ячейках — среднее.

pd.pivot_table(df_clean, values="final_score",
               index="program", columns="year", aggfunc="mean")
# Data Science: 77.0 · 80.5 · 79.2 · 84.2  (1–4 курс)

pd.pivot_table(df_clean, values=["attendance", "final_score"],
               index="program", columns="year", aggfunc="mean")   # два показателя сразу

6. Корреляция

Коэффициент Пирсона от −1 до 1: плюс — растут вместе, минус — одно растёт, другое падает, около 0 — линейной связи нет. .corr() на таблице даёт матрицу «каждый с каждым». Корреляция ≠ причина.

df_clean["attendance"].corr(df_clean["final_score"])   # 0.249 — слабая связь

numeric_columns = ["admission_score", "math_score", "programming_score",
                   "english_score", "attendance", "assignments", "final_score"]
correlation_matrix = df_clean[numeric_columns].corr()

correlation_matrix["final_score"].sort_values(ascending=False)
# programming 0.678 · assignments 0.618 · math 0.590 · admission 0.306
# attendance 0.249 · english 0.165
