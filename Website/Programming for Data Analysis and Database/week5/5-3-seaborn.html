Визуализация: Matplotlib + Seaborn

Какой график выбрать под вопрос. Seaborn рисует по DataFrame: data= — таблица, x=, y=, hue= — названия столбцов. Matplotlib (plt.) — размер, подписи, показ.

Графики под кодом нарисованы прямо на странице по тем же 200 студентам (через Plotly, поэтому можно навести мышь). В Jupyter seaborn выглядит чуть иначе, но смысл тот же.

Сначала слова: что как называется

Matplotlib и SeabornMatplotlib — базовая библиотека графиков (plt). Seaborn (sns) — надстройка: красивые статистические графики одной строкой прямо из DataFrame.sns.boxplot(data=df, …)
Фигура и осиФигура (figure) — весь «лист» с картинкой. Оси (axes, ax) — одна область с графиком на этом листе. На листе может быть несколько осей.plt.figure(figsize=(10, 6))
РаспределениеКакие значения встречаются и как часто: где их много, где мало, есть ли выбросы.у половины студентов балл 74–85
hueРаскрасить по категории: каждая группа своим цветом на одном графике.hue="program"
Ящик с усами (boxplot)Линия в ящике — медиана. Ящик — от 25% до 75% (средняя половина студентов). Усы — остальной обычный диапазон. Точки за усами — выбросы.sns.boxplot
Гистограмма и binsЧисла делятся на интервалы (корзины, bins), высота столбика — сколько значений попало в интервал.bins=15 → 15 интервалов
KDE (плотность)Гладкая кривая вместо столбиков гистограммы. Высоко — значений много, низко — мало.kde=True
РегрессияПрямая, которая лучше всего проходит через облако точек. Показывает общий наклон связи.sns.regplot
FacetingРазбить график на несколько маленьких по категории — по панели на каждое значение.col="gender" → 2 панели

1. Каркас любого графика

Всегда одинаково: создать фигуру нужного размера → нарисовать seaborn-функцией → подписать → показать. tight_layout() убирает наезд подписей.

import pandas as pd
import matplotlib.pyplot as plt
import seaborn as sns

df_clean = pd.read_csv("University Students 2026 New.csv")

plt.figure(figsize=(10, 6))            # ширина, высота в дюймах
# sns.какой_то_plot(data=df_clean, x=..., y=...)
plt.title("…"); plt.xlabel("…"); plt.ylabel("…")
plt.xticks(rotation=30)                # повернуть подписи по оси X
plt.tight_layout()
plt.show()

2. Сравнить категории: barplot и countplot

barplot — высота столбика = значение (тут посчитанное заранее среднее). countplot — сам считает, сколько строк в каждой категории; hue="gender" делит каждый столбик по полу.

average_score = df_clean.groupby("program", as_index=False)["final_score"].mean()
sns.barplot(data=average_score, x="program", y="final_score")

sns.countplot(data=df_clean, x="program", hue="gender")

3. Связь двух чисел: scatterplot и regplot

Точка = студент. regplot добавляет линию регрессии — видно общий наклон. hue — цвет по категории, style — форма точки по второй категории.

sns.scatterplot(data=df_clean, x="attendance", y="final_score")
sns.regplot(data=df_clean, x="attendance", y="final_score")      # + линия

sns.scatterplot(data=df_clean, x="final_score", y="english_score",
                hue="program", style="gender")

4. Динамика по годам: lineplot

Из даты берём год (.dt.year), сводной таблицей получаем «год × программа → среднее», и lineplot рисует по линии на каждый столбец таблицы.

df_clean["admission_date"] = pd.to_datetime(df_clean["admission_date"])
df_clean["admission_year"] = df_clean["admission_date"].dt.year

data_pivot = df_clean.pivot_table(index="admission_year", columns="program",
                                  values="final_score", aggfunc="mean")
sns.lineplot(data=data_pivot, marker="o")

5. Распределение по группам: box, violin, strip, swarm, boxen

boxplot — медиана, квартили, «усы» и выбросы. violinplot — то же + форма плотности (где студентов больше). stripplot — все точки, jitter=True слегка раздвигает их. swarmplot — раскладывает точки без наложения (на больших данных медленный). boxenplot — boxplot с подробными «хвостами», для больших выборок.

sns.boxplot(data=df_clean, x="program", y="final_score")
sns.violinplot(data=df_clean, x="program", y="final_score", inner="quartile")
sns.stripplot(data=df_clean, x="program", y="final_score", jitter=True)
sns.swarmplot(data=df_clean, x="program", y="final_score")
sns.boxenplot(data=df_clean, x="program", y="final_score")

6. Одна числовая колонка: histplot + KDE

Гистограмма делит значения на интервалы (bins) и считает, сколько попало в каждый. kde=True — гладкая кривая плотности: высоко — значений много, несколько горбов — возможно, несколько групп.

sns.histplot(data=df_clean, x="final_score", bins=15)
sns.histplot(data=df_clean, x="programming_score", kde=True)

7. Корреляции одним взглядом: heatmap

На вход — матрица .corr(). annot=True пишет числа в клетках, fmt=".2f" — два знака после запятой.

numeric_columns = ["admission_score", "math_score", "programming_score",
                   "english_score", "attendance", "assignments", "final_score"]
correlation_matrix = df_clean[numeric_columns].corr()

sns.heatmap(correlation_matrix, annot=True, fmt=".2f")

8. Axes-level и figure-level, pairplot

Axes-level (scatterplot, histplot, boxplot) рисуют в одну ось ax. Figure-level (relplot, displot, catplot) сами создают фигуру и умеют разбивать её на панели: col="gender" — отдельный график на каждое значение. height — высота панели в дюймах, aspect — ширина / высота. pairplot — scatter для каждой пары числовых столбцов.

fig, ax = plt.subplots(figsize=(6, 4))                        # axes-level
sns.scatterplot(data=df_clean, x="programming_score", y="final_score", hue="program", ax=ax)

g = sns.relplot(data=df_clean, x="programming_score", y="final_score",
                hue="program", col="gender")                  # figure-level: 2 панели
g.fig.suptitle("Faceting по полу", y=1.02)                    # y=1.02 — чуть выше графиков

sns.displot(data=df_clean, x="programming_score", col="program",
            kde=True, height=3, aspect=1.1)

sns.pairplot(df_clean, hue="program", corner=True, diag_kind="kde")   # corner — только нижний треугольник

Матрица рассеяния по четырём столбцам — похоже на pairplot (без диагонали).
