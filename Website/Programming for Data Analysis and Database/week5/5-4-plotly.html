Plotly: интерактивные графики

В отличие от Matplotlib, график Plotly живой: наводишь мышь — видно значение, колёсиком — зум, клик по легенде — скрыть группу. Здесь графики настоящие — тот же Plotly, те же данные. Потрогай их.

Сначала слова: что как называется

Интерактивный графикГрафик, который реагирует на мышь: подсказка при наведении, зум, перетаскивание, скрытие групп кликом по легенде.Plotly — да, Matplotlib — нет
plotly.express (px)Быстрый способ: одна функция = готовый график из DataFrame.px.scatter(df, x=…, y=…)
figОбъект-график. Его создают, настраивают и показывают fig.show().fig = px.pie(…)
traceОдин набор данных на графике: одна линия, одна группа точек, одни столбики.4 программы = 4 trace
layoutВсё вокруг данных: заголовок, подписи осей, размер, легенда. Меняется через fig.update_layout(...).width=950, height=650
hover (подсказка)Окошко со значениями, когда наводишь мышь на точку.hover_data=["student_id"]
ЛегендаСписок цветов с подписями: какой цвет — какая группа. В Plotly клик по ней скрывает группу.Academic Program
Тепловая картаТаблица, где число в клетке показано цветом: чем сильнее, тем ярче.px.imshow(corr_matrix)

1. Подключение

plotly.express (px) — график одной строкой из DataFrame. graph_objects (go) — ручная сборка, когда нужно больше контроля (будет в части 2). Каждый график: fig = px.…(…) → по желанию fig.update_layout(…) → fig.show().

%pip install -U plotly

import pandas as pd
import plotly.express as px
import plotly.graph_objects as go

df_clean = pd.read_csv("University Students 2026 New.csv")

2. Круговая диаграмма

value_counts() даёт количество по программам, reset_index() превращает его в таблицу из двух столбцов. hole=0.3 — дырка в центре (donut). textinfo="percent+label" — подпись и процент на секторе.

program_counts = df_clean["program"].value_counts().reset_index()
program_counts.columns = ["program", "students"]

fig = px.pie(program_counts, names="program", values="students",
             title="Distribution of Students by Program", hole=0.3)
fig.update_traces(textinfo="percent+label")
fig.show()

3. Тепловая карта корреляций

px.imshow рисует матрицу. text_auto=".2f" — числа в клетках, RdBu_r — красный для +, синий для −. zmin=-1, zmax=1 — шкала всегда от −1 до 1, чтобы цвета не обманывали.

numeric_columns = ["admission_score", "math_score", "programming_score",
                   "english_score", "attendance", "assignments", "final_score"]
corr_matrix = df_clean[numeric_columns].corr()

fig = px.imshow(corr_matrix, text_auto=".2f", color_continuous_scale="RdBu_r",
                zmin=-1, zmax=1, aspect="auto",
                title="Correlation Matrix of Student Performance")
fig.update_layout(width=950, height=650)
fig.show()

4. Scatter с подсказками

color="program" — цвет по программе. hover_data — что ещё показать при наведении. labels — человеческие названия осей. Наведи на точку — увидишь student_id и курс.

fig = px.scatter(df_clean, x="attendance", y="final_score", color="program",
                 hover_data=["student_id", "year"],
                 title="Attendance vs Final Score",
                 labels={"attendance": "Attendance (%)", "final_score": "Final Score",
                         "program": "Academic Program"})
fig.show()

5. 3D scatter

Третья ось z. Мышью можно вращать. hover_name — заголовок подсказки (тут номер студента).

fig = px.scatter_3d(df_clean, x="math_score", y="programming_score", z="final_score",
                    color="program", hover_name="student_id",
                    title="3D Student Performance Analysis")
fig.show()

6. Линия по годам

Год из даты, затем groupby по году и программе. agg(avg_score=("final_score", "mean")) — посчитать среднее и сразу назвать столбец avg_score. dtick=1 — подписи оси X через каждый год, без 2023.5.

df_clean["admission_date"] = pd.to_datetime(df_clean["admission_date"])
df_clean["admission_year"] = df_clean["admission_date"].dt.year

yearly_scores = (df_clean
    .groupby(["admission_year", "program"], as_index=False)
    .agg(avg_score=("final_score", "mean")))

fig = px.line(yearly_scores, x="admission_year", y="avg_score", color="program",
              markers=True, title="Average Final Score by Admission Year")
fig.update_xaxes(dtick=1)
fig.show()

7. Гистограмма с наложением

nbins=15 — желаемое число интервалов. barmode="overlay" — гистограммы программ поверх друг друга, opacity=0.65 — полупрозрачно, чтобы видеть все. Кликни программу в легенде — она спрячется.

fig = px.histogram(df_clean, x="final_score", nbins=15, color="program",
                   barmode="overlay", opacity=0.65,
                   title="Distribution of Final Scores")
fig.update_layout(xaxis_title="Final Score", yaxis_title="Number of Students")
fig.show()

8. Boxplot

Наведи на ящик — Plotly сам покажет min, q1, медиану, q3, max. showlegend=False — легенда лишняя, программы и так подписаны по оси X. points="all" (в ноутбуке закомментировано) добавил бы все точки.

fig = px.box(df_clean, x="program", y="final_score", color="program",
             title="Final Score Distribution by Program")
fig.update_layout(showlegend=False)
fig.show()
