1. Копия и удаление строк с пропусками

copy() — отдельная таблица: правки не попадут в df. dropna() выкидывает строку, если в ней пусто хоть где-то — теряем 16 студентов. subset=[...] — смотреть только на эти столбцы. inplace=True — изменить саму таблицу вместо df_clean = ….

df_clean = df.copy()

df_clean.dropna().shape                          # (184, 15) — минус 16 строк
df_clean = df_clean.dropna()                     # то же, что
df_clean.dropna(inplace=True)

df_clean = df.copy()
df_clean = df_clean.dropna(subset=["math_score"])   # (196, 15) — убраны только те, где нет math

2. Заполнить: 0, среднее или медиана

Ноль — плохая идея для оценок: будто студент получил 0, среднее падает с 83.13 до 81.47. Среднее чувствительно к выбросам (одна очень низкая оценка тянет его вниз), медиана — нет. Поэтому для баллов обычно берут медиану.

df_clean = df.copy()
df_clean["math_score"] = df_clean["math_score"].fillna(0)            # mean → 81.47

mean_english = df_clean["english_score"].mean()                       # 76.28
df_clean["english_score"] = df_clean["english_score"].fillna(mean_english)

df_clean["programming_score"] = df_clean["programming_score"].fillna(
    df_clean["programming_score"].median())                           # 81.0

# так в итоге: медиана для всех баллов
df_clean = df.copy()
for column in ["math_score", "programming_score", "english_score", "attendance"]:
    df_clean[column] = df_clean[column].fillna(df_clean[column].median())

3. Пропуски в категориях — мода

У текста нет среднего (mean() на dormitory выдаст ошибку). Берём моду — самое частое значение. mode() возвращает Series (мод может быть несколько), поэтому [0].

df_clean["dormitory"].mode()        # 0    Yes
df_clean["dormitory"] = df_clean["dormitory"].fillna(df_clean["dormitory"].mode()[0])

df_clean.isna().sum().sum()         # 0 — пропусков не осталось

5. Типы: дата, целые числа, категории

Дата из файла — просто текст. pd.to_datetime делает её датой, и через .dt можно достать год, месяц, день. После fillna баллы остались float64 (75.0) — astype(int) делает их целыми. Тип category — для столбцов с несколькими повторяющимися значениями: меньше памяти.

df_clean["admission_date"] = pd.to_datetime(df_clean["admission_date"])
df_clean["admission_date"].dt.year      # 2026, 2023, 2026, …
df_clean["admission_date"].dt.month     # 3, 9, 7, …

columns = ["math_score", "programming_score", "english_score", "attendance"]
df_clean[columns] = df_clean[columns].astype(int)

categorical_columns = ["gender", "city", "program", "scholarship", "dormitory"]
df_clean[categorical_columns] = df_clean[categorical_columns].astype("category")

6. Проверки диапазонов и допустимых значений

between(0, 100) проверяет каждое значение, all() — что условие верно для всех строк. isin([...]) — что значение из разрешённого списка. В ноутбуке для стипендии написано ["Yes", "Nan"] — это опечатка, получится False. Правильно ["Yes", "No"].

df_clean["attendance"].min(), df_clean["attendance"].max()   # 57, 100
df_clean["attendance"].between(0, 100).all()                # True
df_clean["final_score"].between(0, 100).all()               # True

df_clean["gender"].isin(["Male", "Female"]).all()           # True
df_clean["scholarship"].isin(["Yes", "No"]).all()           # True
