Выбор столбцов и строк, фильтры

Берём чистую таблицу University Students 2026 New.csv и достаём из неё нужное: по названию, по позиции, по условию.

1. Столбцы

Одни скобки и одно имя — получаем Series (один столбец). Двойные скобки — список имён, получаем DataFrame, даже если имя одно.

import pandas as pd
df_clean = pd.read_csv("University Students 2026 New.csv")

type(df_clean["program"])      # Series
type(df_clean[["program"]])    # DataFrame
df_clean[["student_id", "program", "final_score"]]

df_clean[0:5]                  # строки 0…4 срезом (5 строк)

2. loc — по меткам, iloc — по позициям

loc берёт по названию индекса и столбца, и конец диапазона включается: loc[0:5] — 6 строк. iloc берёт по номеру позиции, как обычный срез Python: конец не включается, iloc[0:5] — 5 строк. Столбцы в iloc тоже номерами.

df_clean.loc[0]                                         # строка с индексом 0
df_clean.loc[0:5]                                       # 6 строк: 0…5 включительно
df_clean.loc[0:5, ["student_id", "program", "final_score"]]
df_clean.loc[0:5, "student_id":"math_score"]            # столбцы от … до … включительно (7 шт.)

df_clean.iloc[0]
df_clean.iloc[1:5]                                      # 4 строки: 1, 2, 3, 4
df_clean.iloc[0:5, 0:3]                                 # student_id, gender, city
df_clean.iloc[0:5, [0, 3]]                              # student_id, program

df_clean.loc[0, "final_score"]                          # 62 — одна ячейка по меткам
df_clean.iloc[0, 11]                                    # 62 — она же по позиции (столбец №11)

3. Фильтр по условию — логическая маска

Сравнение со столбцом даёт Series из True/False на каждую строку — это маска. Подставляем её в [ ] — остаются строки с True. Несколько условий: & — И, | — ИЛИ, ~ — НЕ. Каждое условие обязательно в скобках.

high_score = df_clean["final_score"] > 85          # маска: 47 × True
df_clean.loc[high_score, ["student_id", "final_score"]]

df_clean[df_clean["program"] == "Data Science"]    # 54 строки
df_clean[df_clean["program"] != "Data Science"]    # 146

df_clean[(df_clean["program"] == "Data Science") & (df_clean["final_score"] > 85)]   # 12
df_clean[(df_clean["program"] == "Data Science") | (df_clean["program"] == "Cybersecurity")]   # 101
df_clean[~(df_clean["program"] == "Data Science")]                                    # 146

df_clean[(df_clean["program"] == "Data Science") &
         (df_clean["attendance"] >= 80) &
         (df_clean["final_score"] > 85)]                                              # 8

4. isin и between — короче

isin([...]) заменяет цепочку == через |. between(80, 90) заменяет >= 80 & <= 90 (границы включены).

df_clean[df_clean["program"].isin(["Data Science", "Cybersecurity"])]     # 101
df_clean[~df_clean["program"].isin(["Data Science", "Cybersecurity"])]    # 99
df_clean[df_clean["final_score"].between(80, 90)]                         # 94

df_clean[df_clean["program"].isin(["Data Science", "Software Engineering"])
         & df_clean["final_score"].between(80, 90)]                       # 61

5. Сортировка

Сначала фильтр, потом sort_values. По двум столбцам — список, и для каждого своё направление.

df_clean[df_clean["final_score"] >= 85].sort_values("final_score", ascending=False)
# ST181 100 · ST063 98 · ST004 98 …

df_clean.sort_values(["program", "final_score"], ascending=[True, False])
# программы по алфавиту, внутри — баллы от большего к меньшему
