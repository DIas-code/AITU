Pandas: загрузить и осмотреть таблицу

Файл University Students 2026.txt: 200 студентов, 15 столбцов. Прежде чем что-то менять, смотрим: какого размера, какие типы, где пропуски и дубликаты. На этом шаге данные не меняются.

1. Прочитать файл и сохранить в CSV

Внутри .txt — те же строки через запятую, поэтому его читает read_csv. to_csv(..., index=False) — не записывать номер строки 0…199 отдельным столбцом.

import pandas as pd

df = pd.read_csv("University Students 2026.txt")
df.to_csv("University Students 2026.csv", index=False)

df = pd.read_csv("University Students 2026.csv")
df.head()     # первые 5 строк;  df.tail() — последние 5

2. Размер и устройство таблицы

shape — (строки, столбцы), size — всего ячеек. dtypes — тип каждого столбца: числа с пропусками становятся float64, текст — object. info() показывает всё сразу, включая непустые значения.

df.shape                     # (200, 15)
rows, columns = df.shape     # распаковать в две переменные
df.size                      # 3000 = 200 × 15

df.columns.tolist()          # ['student_id', 'gender', 'city', 'program', 'year', …]
df.index                     # RangeIndex(start=0, stop=200, step=1)
df.dtypes                    # year int64 · math_score float64 · program object …
df.info()                    # типы + сколько непустых в каждом столбце

df.memory_usage(deep=True)          # байты на столбец; deep=True честно считает строки
df.memory_usage(deep=True).sum()

3. Статистика и категории

describe() — для числовых: count, mean, std, min, 25%, медиана (50%), 75%, max. Уже тут видно пропуски: у math_score count 196, а не 200. include="all" добавляет для текста unique, top (самое частое) и freq.

df.describe()                # math_score: count 196, mean 83.13, 50% 84.5
df.describe(include="all")   # city: unique 7, top Astana, freq 56

df.nunique()                 # сколько разных значений в каждом столбце
df["program"].unique()       # сами значения
df["program"].value_counts() # Software Engineering 62 · Data Science 54 · Cybersecurity 47 · IT Management 37
df["program"].value_counts(normalize=True).mul(100).round(2)   # 31.0 · 27.0 · 23.5 · 18.5 (%)

4. Пропуски

isna() даёт таблицу True/False. True = 1, поэтому sum() — число пропусков, mean() — их доля. Первая sum() — по столбцам, вторая — по всей таблице.

df.isna().sum()            # math 4 · programming 3 · english 5 · attendance 3 · dormitory 2
df.isna().sum().sum()      # 17
df.isna().mean().mul(100).round(2)   # math_score 2.0 % …
df.notna().sum()           # наоборот: сколько заполнено

Карта пропусков: строка — студент, столбец — признак, красная клетка — NaN.

5. Дубликаты и уникальность ID

duplicated() — True, если строка повторяет одну из предыдущих. keep=False помечает все копии, а не только вторую. Здесь повторов нет, и каждый student_id уникален.

df.duplicated().sum()                          # 0
df[df.duplicated(keep=False)]                  # все строки-повторы (тут пусто)
df[df["student_id"].duplicated(keep=False)]    # повторы только по ID
df["student_id"].is_unique                     # True

df["final_score"].agg(["min", "max"])          # 57 и 100 — в пределах 0…100

6. Сводная таблица качества

Собираем главные проверки в одну таблицу — по столбцу на проверку. Сразу видно проблемные признаки. value_counts(dropna=False) считает и NaN как отдельную категорию.

for column in ["gender", "city", "program", "year", "scholarship", "dormitory"]:
    print(f"\n--- {column} ---")
    print(df[column].value_counts(dropna=False))   # dormitory: Yes 107 · No 91 · NaN 2

data_quality = pd.DataFrame({
    "Data Type": df.dtypes,
    "Non-Null": df.notna().sum(),
    "Missing": df.isna().sum(),
    "Missing %": (df.isna().mean() * 100).round(2),
    "Unique": df.nunique()
})
