Новые столбцы, масштабирование, кодирование

Последний шаг перед машинным обучением: посчитать новые признаки, привести числа к одному масштабу, превратить текст в числа.

Сначала слова: что как называется

Признак (feature)Столбец, который модель использует как входные данные. Новые признаки можно посчитать из старых.average_score из трёх оценок
axisНаправление расчёта. axis=0 — вниз по столбцу (для всех студентов), axis=1 — вдоль строки (для одного студента).mean(axis=1) — среднее студента
applyПрименить свою функцию к каждому значению столбца по очереди.92 → "Excellent"
МасштабированиеПривести числовые признаки к сопоставимым шкалам, чтобы модель не считала большие числа важнее.баллы до 120 и проценты до 100
Стандартизация (z-score)Из значения вычесть среднее и поделить на std. 0 — как у всех, −2 — сильно ниже среднего.StandardScaler
Нормализация (min-max)Сжать значения в отрезок от 0 до 1: минимум → 0, максимум → 1.MinMaxScaler
КодированиеПревратить текст в числа — модели понимают только числа."Yes" → 1, "No" → 0
fit / transformfit — изучить данные (найти среднее, min, max, список категорий). transform — применить. fit_transform — оба сразу.scaler.fit_transform(X)

1. Новый столбец из других

Арифметика со столбцами идёт сразу по всем строкам. То же короче: mean(axis=1) — среднее по строке, отдельно для каждого студента (axis=0 было бы по столбцу).

df_clean["average_score"] = (
    df_clean["math_score"] + df_clean["programming_score"] + df_clean["english_score"]
) / 3
# ST001: (75 + 59 + 80) / 3 = 71.33

df_clean["average_score_1"] = df_clean[
    ["math_score", "programming_score", "english_score"]
].mean(axis=1)                     # то же самое

2. apply — своя функция на каждое значение

Пишем обычную функцию для одного числа, apply вызывает её для каждой строки столбца. Условия проверяются сверху вниз: 92 подходит под первое (≥ 90) и дальше не идёт.

def performance_level(score):
    if score >= 90:
        return "Excellent"
    elif score >= 75:
        return "Good"
    elif score >= 60:
        return "Satisfactory"
    else:
        return "Low"

df_clean["performance_level"] = df_clean["final_score"].apply(performance_level)
df_clean["performance_level"].value_counts()
# Good 133 · Satisfactory 49 · Excellent 16 · Low 2

4. Масштабирование: StandardScaler и MinMaxScaler

Баллы поступления до 120, посещаемость до 100 — у признаков разные масштабы, и многие модели решат, что большие числа важнее. StandardScaler: z = (x − среднее) / std → среднее 0, разброс 1. MinMaxScaler: (x − min) / (max − min) → всё от 0 до 1. Результат — массив NumPy, поэтому заворачиваем в DataFrame; исходный df_clean не меняется.

from sklearn.preprocessing import StandardScaler, MinMaxScaler

features = ["admission_score", "math_score", "programming_score",
            "english_score", "attendance", "assignments"]

standard_scaler = StandardScaler()
standardized_data = standard_scaler.fit_transform(df_clean[features])
df_standardized = pd.DataFrame(standardized_data, columns=features)
# ST001 attendance: -2.207 — сильно ниже среднего

minmax_scaler = MinMaxScaler()
df_normalized = pd.DataFrame(minmax_scaler.fit_transform(df_clean[features]),
                             columns=features)
df_normalized.min()   # все 0
df_normalized.max()   # все 1

5. Текст → числа: LabelEncoder и OneHotEncoder

LabelEncoder — каждой категории номер по алфавиту: No → 0, Yes → 1. Годится для «да/нет». Для программ номера 0–3 создали бы ложный порядок («Software Engineering больше Cybersecurity»), поэтому OneHotEncoder: по столбцу на каждую категорию, 1 там, где студент. sparse_output=False — вернуть обычный массив, а не экономную разреженную матрицу.

from sklearn.preprocessing import LabelEncoder, OneHotEncoder

label_encoder = LabelEncoder()
df_clean["scholarship_encoded"] = label_encoder.fit_transform(df_clean["scholarship"])
label_encoder.classes_          # ['No', 'Yes'] → 0, 1

onehot_encoder = OneHotEncoder(sparse_output=False)
program_encoded = onehot_encoder.fit_transform(df_clean[["program"]])   # двойные скобки: нужна таблица
onehot_encoder.get_feature_names_out(["program"])
# ['program_Cybersecurity', 'program_Data Science', 'program_IT Management', 'program_Software Engineering']

program_encoded_df = pd.DataFrame(program_encoded,
                                  columns=onehot_encoder.get_feature_names_out(["program"]),
                                  index=df_clean.index)
