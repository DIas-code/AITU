Архивы: резервная копия проекта

Упаковать файлы проекта в ZIP и TAR, посмотреть содержимое, распаковать один файл или всё сразу.

1. Создать ZIP

Модуль zipfile встроен в Python. Режим "w" создаёт архив заново. Без параметра compression файлы просто складываются, а не сжимаются.

import zipfile

with zipfile.ZipFile("project_backup.zip", "w") as archive:
    archive.write("file3.csv")
    archive.write("file2.jpg")
    archive.write("file1.xlsx")

2. Со сжатием и дописыванием

ZIP_DEFLATED — обычное сжатие. Есть ещё ZIP_STORED (без сжатия), ZIP_BZIP2, ZIP_LZMA. Режим "a" добавляет файл в существующий архив.

with zipfile.ZipFile("project_backup1.zip", "w", compression=zipfile.ZIP_DEFLATED) as archive:
    archive.write("file3.csv")
    archive.write("file2.jpg")
    archive.write("file1.xlsx")

with zipfile.ZipFile("project_backup1.zip", "a", compression=zipfile.ZIP_DEFLATED) as archive:
    archive.write("students.json")

3. Что внутри архива

namelist() — просто имена, infolist() — подробности. Маленький файл после сжатия может стать больше: сжатию нужны служебные данные, а выигрыш бывает только на больших файлах с повторами.

with zipfile.ZipFile("project_backup1.zip", "r") as archive:
    archive.namelist()            # ['file3.csv', 'file2.jpg', ...]
    for f in archive.infolist():
        print(f.filename, f.file_size, f.compress_size)
# file3.csv 452 245        — сжался почти вдвое
# file4.txt 20 22          — маленький файл стал больше

    if "file1.xlsx" in archive.namelist():
        print("file1.xlsx found")

4. Распаковать

extract — один файл, extractall — всё. Второй аргумент — папка назначения, её создадут автоматически.

with zipfile.ZipFile("project_backup1.zip", "r") as archive:
    archive.extract("students.json", "extracted")
    archive.extractall("restored_project")

5. Заархивировать целую папку

os.walk обходит папку со всеми подпапками. arcname задаёт путь внутри архива: relpath убирает лишнее начало, чтобы в ZIP лежало file1.xlsx, а не restored_project/file1.xlsx.

import os

project_folder = "restored_project"
with zipfile.ZipFile("project_backup1.zip", "w", compression=zipfile.ZIP_DEFLATED) as archive:
    for root, directories, files in os.walk(project_folder):
        for file in files:
            file_path = os.path.join(root, file)
            archive.write(file_path, arcname=os.path.relpath(file_path, project_folder))

6. TAR и .tar.gz

TAR сначала складывает всё в один контейнер, а сжатие (gz) идёт поверх, одним куском. Поэтому .tar.gz часто меньше ZIP, где каждый файл сжимается отдельно. На Linux это стандарт.

import tarfile

with tarfile.open("project_backup2.tar", "w") as archive:        # без сжатия
    archive.add("restored_project", arcname="restored_project")

with tarfile.open("project_backup3.tar.gz", "w:gz") as archive:  # со сжатием gzip
    archive.add("restored_project", arcname="restored_project")

7. Читать и распаковывать TAR

Режим "r:gz" — чтение сжатого архива. filter="data" — безопасная распаковка: без него Python 3.12+ выдаёт предупреждение, а архив из чужих рук может записать файлы куда не надо.

with tarfile.open("project_backup3.tar.gz", "r:gz") as archive:
    archive.getnames()                  # ['restored_project', 'restored_project/file1.xlsx', ...]
    for m in archive.getmembers():
        print(m.name, m.size, m.isfile(), m.isdir())

    member = archive.getmember("restored_project/file1.xlsx")
    archive.extract(member, path="extracted", filter="data")
    archive.extractall(path="restored_project1", filter="data")
