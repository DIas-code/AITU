Pandas и Excel: анализ отчёта

Берём student_report.xlsx из прошлой лекции: смотрим данные, выбираем, фильтруем, считаем и сохраняем обратно в Excel.

1. Прочитать и осмотреть

Главное отличие от openpyxl: Pandas сразу даёт таблицу и инструменты анализа. Эти пять команд — первое, что делают с любыми новыми данными.

import pandas as pd

df = pd.read_excel("student_report.xlsx")

df.head()       # первые 5 строк
df.shape        # (5, 7) — строк, столбцов
df.columns      # названия столбцов
df.info()       # типы и сколько непустых значений
df.describe()   # count, mean, std, min, max по числовым столбцам

2. Выбрать столбцы и строки

Один столбец — в квадратных скобках, несколько — списком (двойные скобки). iloc выбирает строки по номеру позиции.

df["Student"]                                      # один столбец (Series)
df[["Student", "Assignment 1", "Assignment 2"]]    # несколько — таблица

df.iloc[0]      # первая строка
df.iloc[0:3]    # первые три строки

3. Фильтр по условию

Условие даёт маску True/False, таблица по маске оставляет только подходящие строки. Несколько условий — через & (и) или | (или), каждое в скобках.

df[df["Assignment 1"] >= 80]                                  # Amina, Dias

df[(df["Assignment 1"] >= 80) & (df["Assignment 2"] >= 80)]

4. Новые столбцы

mean(axis=1) — среднее по строке (по каждому студенту). apply применяет функцию к каждому значению столбца.

df["Average"] = df[["Assignment 1", "Assignment 2", "Assignment 3"]].mean(axis=1)

df["Result"] = df["Average"].apply(lambda x: "Pass" if x >= 70 else "Fail")

5. Сохранить в Excel

index=False — не записывать служебный номер строки Pandas отдельным столбцом.

df.to_excel("student_results.xlsx", index=False)

6. Несколько листов в одном файле

ExcelWriter открывает один файл, и в него можно записать несколько таблиц — каждую на свой лист.

passed = df[df["Result"] == "Pass"]
failed = df[df["Result"] == "Fail"]

with pd.ExcelWriter("student_analysis.xlsx") as writer:
    df.to_excel(writer, sheet_name="All Students", index=False)
    passed.to_excel(writer, sheet_name="Passed", index=False)
    failed.to_excel(writer, sheet_name="Failed", index=False)
