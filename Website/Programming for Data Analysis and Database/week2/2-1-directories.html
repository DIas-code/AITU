Папки, пути и текстовые файлы

Создаём структуру проекта ai_course_project/ с папками data, reports, logs, backup и ведём в ней лог-файл.

1. Где я нахожусь и что здесь лежит

Модуль os — связь с операционной системой. Все относительные пути считаются от текущей папки, поэтому сначала надо знать, где ты.

import os

os.getcwd()             # текущая рабочая папка
os.listdir()            # что в ней лежит (имена файлов и папок)
os.listdir("extracted") # содержимое другой папки

2. Создать папки проекта

os.path.join склеивает путь с правильным разделителем для Windows / Mac / Linux — вместо ручного "a/b".

os.mkdir("ai_course_project")

for folder in ["data", "reports", "logs", "backup"]:
    os.mkdir(os.path.join("ai_course_project", folder))

os.path.join("ai_course_project", "data", "students.txt")
# 'ai_course_project/data/students.txt'

3. Проверить путь и создать вложенные папки

mkdir падает с ошибкой, если папка уже есть. makedirs(..., exist_ok=True) создаёт сразу несколько уровней и спокойно пропускает существующие.

os.path.exists("ai_course_project")   # True — путь существует
os.path.isdir("ai_course_project")    # True — это папка
os.path.isfile("ai_course_project")   # False — не файл

os.makedirs("ai_course_project/data/raw", exist_ok=True)

4. То же самое через pathlib

pathlib — современная замена os.path: путь — это объект, части склеиваются оператором /. parents=True создаёт недостающие родительские папки.

from pathlib import Path

project = Path("ai_course_project1")
for name in ["data1", "reports1", "logs1", "backup1"]:
    (project / name).mkdir(parents=True, exist_ok=True)

5. Части пути

Имя, расширение, родительская папка — без ручного разрезания строки.

file_path = Path("ai_course_project/data/students.txt")

file_path.name       # 'students.txt'
file_path.stem       # 'students'   — имя без расширения
file_path.suffix     # '.txt'
file_path.parent     # ai_course_project/data
file_path.resolve()  # полный (абсолютный) путь
file_path.exists()   # False — файла пока нет

6. Записать текстовый файл

with open(...) сам закроет файл после блока. Режим "w" создаёт файл или перезаписывает его целиком. \n — перенос строки.

log_file = Path("ai_course_project/logs/application.log")

with open(log_file, "w", encoding="utf-8") as file:
    file.write("Application started\n")
    file.write("Student dataset loaded\n")
    file.write("Processing completed\n")

7. Прочитать файл: три способа

read() — всё одной строкой, readline() — одну строку, readlines() — список строк. Для больших файлов лучше идти циклом по строкам: файл не грузится в память целиком.

with open(log_file, "r", encoding="utf-8") as file:
    content = file.read()        # 'Application started\nStudent ...'

with open(log_file, "r", encoding="utf-8") as file:
    first_line = file.readline() # 'Application started\n'

with open(log_file, "r", encoding="utf-8") as file:
    lines = file.readlines()     # ['Application started\n', ...]

with open(log_file, "r", encoding="utf-8") as file:
    for line in file:
        print(line.strip())      # strip() убирает \n и пробелы по краям

8. Дописать, найти, посчитать

Режим "a" добавляет в конец, не стирая старое. Поиск — обычная проверка in по каждой строке.

with open(log_file, "a", encoding="utf-8") as file:
    file.write("Report generated\n")

with open(log_file, "r", encoding="utf-8") as file:
    for line in file:
        if "completed" in line.lower():
            print(line.strip())          # Processing completed

with open(log_file, "r", encoding="utf-8") as file:
    line_count = sum(1 for line in file) # 4 строки

9. Режимы open() и бинарные файлы

"r" — чтение, "w" — перезапись, "a" — дописать, "b" — бинарный режим для картинок, архивов и т. п. В бинарном режиме получаешь байты, а не текст.

with open("street.jpg", "rb") as f:
    data = f.read()

data[:5]     # первые 5 байт файла
type(data)   # bytes
