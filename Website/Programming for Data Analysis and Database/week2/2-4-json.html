JSON: данные курса и студентов

JSON — текстовый формат для хранения и обмена данными. В отличие от CSV умеет вложенность: списки внутри словарей и наоборот.

1. Данные в Python и запись в файл

Словарь Python почти один в один становится JSON. json.dump пишет в файл, indent=4 — с отступами, чтобы файл читался глазами.

import json

students = {
    "course": "Programming for AI",
    "semester": 1,
    "students": [
        {"id": 1, "name": "Amina", "scores": [85, 90, 88], "active": True},
        {"id": 2, "name": "Arman", "scores": [70, 75, 80], "active": True},
        {"id": 3, "name": "Dias",  "scores": [95, 92, 96], "active": True},
    ],
}

with open("students.json", "w", encoding="utf-8") as file:
    json.dump(students, file, indent=4)

2. Прочитать и добраться до значений

json.load возвращает обычный словарь. Дальше — ключи и индексы по цепочке, шаг за шагом вглубь.

with open("students.json", "r", encoding="utf-8") as file:
    data = json.load(file)            # dict

data["course"]                        # 'Programming for AI'
data["students"][0]                   # первый студент — словарь
data["students"][0]["name"]           # 'Amina'
data["students"][0]["scores"]         # [85, 90, 88]

for s in data["students"]:
    print(s["id"], s["name"], round(sum(s["scores"]) / len(s["scores"]), 2))
# 1 Amina 87.67 · 2 Arman 75.0 · 3 Dias 94.33

3. Изменить и сохранить

Изменения делаются в памяти. Файл на диске не меняется, пока снова не вызовешь json.dump.

for s in data["students"]:
    if s["name"] == "Arman":
        s["scores"][1] = 82          # вторая оценка: 75 → 82

with open("students.json", "w", encoding="utf-8") as file:
    json.dump(data, file, indent=4)

4. Добавить поля и записи

В словарь можно просто присвоить новый ключ, в список — добавить элемент через append.

for s in data["students"]:
    s["average"] = round(sum(s["scores"]) / len(s["scores"]), 2)
    s["result"] = "Pass" if s["average"] >= 70 else "Fail"

data["students"].append(
    {"id": 4, "name": "Aigerim", "scores": [60, 68, 65], "active": True}
)

5. Удалить поле и запись

pop(key, None) удаляет ключ и не падает, если его нет. Запись удобнее убрать, собрав новый список без неё.

for s in data["students"]:
    s.pop("active", None)            # убрать поле у всех

data["students"] = [s for s in data["students"] if s["name"] != "Aigerim"]

with open("students.json", "w", encoding="utf-8") as file:
    json.dump(data, file, indent=4, ensure_ascii=False)
# ensure_ascii=False — кириллица сохранится буквами, а не кодами А...

6. JSON-строка вместо файла

Буква s на конце = string. dump / load работают с файлом, dumps / loads — со строкой (например, ответ от API).

student = {"name": "Amina", "age": 22, "city": "Astana"}
json_string = json.dumps(student, indent=4)   # dict → str

json_string = '{"model": "RandomForest", "accuracy": 0.91, "trained": true}'
config = json.loads(json_string)              # str → dict
config["accuracy"]                            # 0.91
# true в JSON → True в Python
