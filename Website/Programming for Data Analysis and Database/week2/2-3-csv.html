CSV: таблица студентов

Файл students.csv с колонками id, name, assignment1–3: создать, прочитать, посчитать средние, изменить, сохранить обработанную версию.

1. Записать CSV

CSV — таблица в текстовом файле, значения через запятую. Модуль csv встроен в Python. newline="" обязателен: без него в Windows между строками появляются пустые.

import csv

header = ["id", "name", "assignment1", "assignment2", "assignment3"]
students = [
    [1, "Amina", 85, 90, 88],
    [2, "Arman", 70, 75, 80],
    [3, "Dias", 95, 92, 96],
    [4, "Aigerim", 60, 68, 65],
]

with open("students.csv", "w", newline="", encoding="utf-8") as file:
    writer = csv.writer(file)
    writer.writerow(header)      # одна строка
    writer.writerows(students)   # много строк сразу

2. Прочитать построчно

csv.reader отдаёт каждую строку списком, и все значения — строки. Для расчётов их нужно переводить в int. next(reader) забирает первую строку (заголовок), и цикл дальше идёт только по данным.

with open("students.csv", "r", encoding="utf-8") as file:
    reader = csv.reader(file)
    header = next(reader)          # ['id', 'name', 'assignment1', ...]
    for row in reader:
        name, a1 = row[1], int(row[2])
        print(name, a1)            # Amina 85 ...

3. Читать по названиям колонок

DictReader превращает строку в словарь «колонка → значение». Код читается понятнее и не ломается, если колонки поменяют местами.

with open("students.csv", "r", encoding="utf-8") as file:
    for student in csv.DictReader(file):
        print(student["name"], student["assignment1"])
# {'id': '1', 'name': 'Amina', 'assignment1': '85', ...}

4. Средний балл и фильтр

Считаем среднее каждого студента и выводим только тех, у кого оно не ниже 80.

with open("students.csv", "r", encoding="utf-8") as file:
    for student in csv.DictReader(file):
        scores = [int(student["assignment1"]),
                  int(student["assignment2"]),
                  int(student["assignment3"])]
        average = sum(scores) / len(scores)
        if average >= 80:
            print(student["name"], round(average, 2))
# Amina 87.67
# Dias 94.33

5. Добавить запись

Режим "a" дописывает строку в конец файла, остальное не трогает.

with open("students.csv", "a", newline="", encoding="utf-8") as file:
    csv.writer(file).writerow([5, "Miras", 78, 85, 80])

6. Изменить существующую запись

CSV нельзя поправить «на месте». Схема всегда такая: прочитать всё в память → изменить нужное → перезаписать файл целиком. fieldnames запоминаем, чтобы записать тот же заголовок.

rows = []
with open("students.csv", "r", encoding="utf-8") as file:
    reader = csv.DictReader(file)
    fieldnames = reader.fieldnames
    for student in reader:
        if student["name"] == "Arman":
            student["assignment2"] = "82"    # было 75
        rows.append(student)

with open("students.csv", "w", newline="", encoding="utf-8") as file:
    writer = csv.DictWriter(file, fieldnames=fieldnames)
    writer.writeheader()
    writer.writerows(rows)

7. Новые колонки и новый файл

Добавляем в словарь каждого студента вычисленные поля average и result и сохраняем в отдельный файл — исходные данные остаются нетронутыми.

processed = []
with open("students.csv", "r", encoding="utf-8") as file:
    for s in csv.DictReader(file):
        avg = (int(s["assignment1"]) + int(s["assignment2"]) + int(s["assignment3"])) / 3
        s["average"] = round(avg, 2)
        s["result"] = "Pass" if avg >= 70 else "Fail"
        processed.append(s)

fieldnames = ["id", "name", "assignment1", "assignment2", "assignment3", "average", "result"]
with open("students_processed.csv", "w", newline="", encoding="utf-8") as file:
    writer = csv.DictWriter(file, fieldnames=fieldnames)
    writer.writeheader()
    writer.writerows(processed)

8. То же в Pandas — одной строкой

Модуль csv показывает, как устроен файл. Pandas сразу даёт таблицу (DataFrame) с типами чисел, с которой удобно анализировать.

import pandas as pd

df = pd.read_csv("students_processed.csv")
print(df)
type(df)   # pandas.DataFrame
