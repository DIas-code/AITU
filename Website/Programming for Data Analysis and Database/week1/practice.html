2. Оценка по баллу (задача 6)

Порядок условий важен: сначала проверяем самое строгое (≥ 90). Если первой поставить проверку ≥ 70, балл 95 получит «Good», и до «Excellent» дело не дойдёт.

for score in [95, 82, 65, 40]:
    if score >= 90:
        print("Excellent")
    elif score >= 70:
        print("Good")
    elif score >= 50:
        print("Satisfactory")
    else:
        print("Fail")

3. Список: доступ и изменения (задачи 7–8)

[-1] — последний элемент без len. remove удаляет по значению, sort меняет сам список. Фильтр — цикл с if на каждой итерации.

scores = [78, 85, 92, 67, 88]
scores[0], scores[-1], len(scores)       # 78, 88, 5
min(scores), max(scores), sum(scores), sum(scores) / len(scores)   # 67 92 410 82.0

scores.append(95)
scores.remove(67)
scores.sort()             # [78, 85, 88, 92, 95]

for s in [78, 85, 92, 67, 88]:
    if s >= 80:
        print(s)          # 85 92 88

6. Список словарей = маленький датасет (задача 13)

Каждый словарь — строка таблицы, ключи — столбцы. Ровно так потом выглядят данные для Pandas.

students = [{"name": "Aruzhan", "score": 85}, {"name": "Daniel", "score": 72},
            {"name": "Amina", "score": 94}, {"name": "Mark", "score": 61},
            {"name": "Ali", "score": 88}]

[s["name"] for s in students]                    # все имена
[s["name"] for s in students if s["score"] >= 80]  # Aruzhan, Amina, Ali
sum(s["score"] for s in students) / len(students)  # 80.0
max(students, key=lambda s: s["score"])["name"]   # 'Amina'
sum(1 for s in students if s["score"] >= 50)       # 5 сдали

7. Функции (задачи 14, 17)

Функция — один раз написать, много раз вызвать. Нашёл ошибку — исправляешь в одном месте, а не в каждой копии кода.

def calculate_average(values):
    return sum(values) / len(values)

def get_status(score):
    if score >= 90:
        return "Excellent"
    elif score >= 70:
        return "Good"
    elif score >= 50:
        return "Satisfactory"
    return "Fail"

get_status(95), get_status(55)      # 'Excellent', 'Satisfactory'

group_a_scores = [10, 20, 30]       # вместо a и b — понятные имена
group_b_scores = [50, 60, 70]
calculate_average(group_a_scores)   # 20.0
calculate_average(group_b_scores)   # 60.0

9. Индивидуальная задача: склад (задача 18)

Стоимость позиции = цена × количество. Категория — функция, чтобы правило было в одном месте. Строка в нужном формате — f-строка.

products = [
    {"name": "Laptop", "price": 450000, "quantity": 3},
    {"name": "Mouse", "price": 7000, "quantity": 15},
    {"name": "Keyboard", "price": 15000, "quantity": 10},
    {"name": "Monitor", "price": 120000, "quantity": 5},
    {"name": "Headphones", "price": 25000, "quantity": 8},
]

def product_category(price):
    if price < 20000:
        return "Budget"
    elif price <= 100000:
        return "Medium"
    return "Expensive"

for p in products:
    p["value"] = p["price"] * p["quantity"]

sum(p["value"] for p in products)              # 2 405 000 — весь склад
max(products, key=lambda p: p["price"])["name"]   # 'Laptop'
[p["name"] for p in products if p["price"] > 20000]
sum(p["price"] for p in products) / len(products) # 123400.0

for p in products:
    print(f'{p["name"]} | {p["price"]} | {product_category(p["price"])}')
# Laptop | 450000 | Expensive
