Числа, циклы и условия

Какие бывают числа в Python, как считать в цикле и как программа выбирает, что делать.

1. Целые числа int

В Python целые числа не переполняются: int растёт сколько нужно, ограничение только память. Числа можно писать в двоичной, восьмеричной и шестнадцатеричной системе.

2 ** 10        # 1024
2 ** 1000      # огромное число — и это нормально

0b11111111     # 255 — двоичная
0o76           # 62  — восьмеричная: 7·8 + 6
0xF3           # 243 — шестнадцатеричная: 15·16 + 3

int("12345")   # строка → число

2. Дроби: Fraction, Decimal, float

Fraction — точные обыкновенные дроби. Decimal — точные десятичные (для денег). float — обычные дробные числа для науки: быстрые, но с погрешностью.

from fractions import Fraction
Fraction(5, 27) + Fraction(91, 11)   # 2512/297 — без округления

from decimal import Decimal
Decimal("12.3456786777") + Decimal("0.9876")   # 13.3332786777 — точно
# Decimal создают из строки, а не из float

2 ** -1    # 0.5  — float
2 / 5      # 0.4
10 / 5     # 2.0  — деление через / всегда даёт float
float("0.9")

3. Обмен значениями

В Python не нужна временная переменная — это распаковка кортежа.

a, b = 7, 12
a, b = b, a     # теперь a = 12, b = 7

4. Счётчики и сумма

x += 1 — короткая запись x = x + 1. Так считают, сколько раз что-то случилось. Сумма — переменная-накопитель, которая начинается с нуля.

x = y = 10
x += 1       # 11 — инкремент
y -= 1       # 9  — декремент

s = 0
for x in 4, 6, 15:
    s += x
s            # 25

5. Цикл while

Повторяет тело, пока условие истинно. Если условие никогда не станет ложным — цикл будет бесконечным. Если ложно сразу — не выполнится ни разу.

x = 0
while x < 100:
    print(x)       # 0, 10, 20, ..., 90
    x += 10

x = 1
while x > 0:       # бесконечный цикл: x только растёт
    x += 1

6. Прогрессии и range

Арифметическая прогрессия — такая частая задача, что для неё есть range(start, stop, step). Как и в срезах, stop не входит. Геометрическую делают через *=.

for x in range(10, 50, 5):
    print(x)            # 10 15 20 ... 45 — 50 не входит

print(*range(0, 10))    # 0 1 2 ... 9
print(*range(9, -1, -1))  # 9 8 ... 0 — обратный отсчёт

x = 1
while x < 100:
    print(x)            # 1 2 4 8 16 32 64
    x *= 2

7. Условия if / else

if выполняет блок только при истинном условии, else — во всех остальных случаях. f-строка подставляет значения переменных в текст: {18 - x}.

x = int(input("Какое сегодня число? "))
if x < 1 or x > 31:
    print("Такого не может быть!")

age = int(input("Сколько вам лет? "))
if age < 18:
    print(f"Вам нельзя смотреть этот фильм! Приходите через {18 - age} лет.")
else:
    print("Фильм загружается...")

8. Вложенные условия и elif

Определяем четверть точки. Вложенные if быстро «уезжают» вправо. elif делает то же самое плоско: проверяет условия по очереди до первого истинного. Последний else ловит точки на осях — их легко забыть, поэтому код надо тестировать.

x, y = map(int, input("Координаты через пробел: ").split())

if y > 0 and x > 0:
    print("I четверть")
elif y > 0 and x < 0:
    print("II четверть")
elif y < 0 and x < 0:
    print("III четверть")
elif y < 0 and x > 0:
    print("IV четверть")
else:
    print("На оси или в начале координат")
# and — «и», or — «или», not — «не»
