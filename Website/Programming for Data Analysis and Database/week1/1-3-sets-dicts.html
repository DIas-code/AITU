Неделя 1 · Лекция 1.3

Множества и словари

set — уникальные элементы и быстрый поиск. dict — пары «ключ → значение». В конце — подсчёт голосов на выборах.

1. Множество: только уникальные

Повторы в множестве исчезают сами, порядок не гарантирован — зато проверка «есть ли элемент» очень быстрая. Пустое множество — только set(), потому что {} — это пустой словарь.

{2, 3, 5, 7, 7, 5}          # {2, 3, 5, 7}
set(range(10, 100, 10))     # из любого итерируемого
set()                       # пустое множество

set([5, 7, 8, 5, 2, 2, 1])  # убрать дубликаты из списка → {1, 2, 5, 7, 8}

2. Уникальные строки из файла

Типичная задача: в файле растения с повторами — сколько разных? Set comprehension собирает множество прямо при чтении.

with open("plants.txt", encoding="utf8") as file:
    plants = {line.strip() for line in file}
len(plants)     # сколько уникальных названий

# с большой буквы — те, что кончаются на «а»
print(*map(str.title, filter(lambda p: p[-1] == "а", plants)))

3. Принадлежность и сравнение

in / not in — есть ли элемент. <= — подмножество, < — строгое подмножество. Два множества могут быть ни больше, ни меньше, ни равны друг другу — поэтому сортировать множества бессмысленно.

plants = {"береза", "липа", "дуб", "клен", "сосна", "ромашка", "роза", "мак", "ландыш"}
trees = {"береза", "липа", "дуб", "клен", "сосна"}
flowers = {"ромашка", "роза", "мак", "ландыш", "липа"}

"сосна" in plants      # True
flowers <= plants      # True  — все цветы есть среди растений
plants > trees         # True  — строгое надмножество
flowers < trees, flowers > trees, flowers == trees   # все False

4. Операции над множествами

Как в математике. У каждой операции есть оператор и метод с тем же смыслом. Разность несимметрична: от перестановки меняется результат.

flowers & trees   # пересечение: {'липа'}               .intersection()
flowers | trees   # объединение: всё вместе             .union()
flowers - trees   # разность: цветы, которые не деревья  .difference()
trees - flowers   # другой результат!
flowers ^ trees   # симметрическая разность: всё, кроме общего  .symmetric_difference()

{name[::-1] for name in plants}   # set comprehension

5. Добавить и удалить

add — один элемент, update — сразу много. Уже существующий элемент не добавится второй раз, и ошибки не будет. remove падает, если элемента нет, discard — нет.

garden = {"липа", "береза", "роза"}
garden.add("лаванда")
garden.update(["вишня", "яблоня", "роза"])   # «роза» не задвоится

garden.remove("береза")
garden.remove("береза")    # KeyError — уже нет
garden.discard("береза")   # молча ничего не делает

6. Словарь: ключ → значение

Ключи уникальны (как множество), значения могут повторяться. Удобно собрать словарь из двух списков через zip. Цикл по словарю идёт по ключам.

capitals = {"Казахстан": "Астана", "Китай": "Пекин"}

states = "Казахстан", "Украина", "Китай"
cities = "Астана", "Киев", "Пекин"
capitals = dict(zip(states, cities))

legs = {"корова": 4, "кошка": 4, "петух": 2}
for key in legs:
    print(key, legs[key])

7. Чтение, запись, удаление

Обращение к несуществующему ключу — ошибка KeyError. Поэтому сначала проверяй in или бери get со значением по умолчанию. Присваивание либо создаёт ключ, либо меняет значение.

legs["кошка"]              # 4
legs["слон"]               # KeyError
"слон" in legs             # False
legs.get("слон", "не знаю")   # 'не знаю' — без ошибки

legs["осёл"] = 4           # новый ключ
legs["осёл"] = 3           # тот же ключ — значение заменилось
del legs["петух"]          # удалить пару

{a: len(s) for a, s in zip(["корова", "кошка"], ["му", "мяу"])}   # dict comprehension

8. Задача: подсчёт голосов

Множество — чтобы быстро отбросить несуществующие фамилии. Словарь — чтобы считать голоса за каждого. sorted(..., key=..., reverse=True) — рейтинг по убыванию голосов.

with open("students.txt", encoding="utf8") as file:
    students = {line.strip() for line in file}

votes = {}
with open("elections.txt", encoding="utf8") as file:
    for line in file:
        name = line.strip()
        if name not in students:
            continue                   # шуточный голос — пропустить
        votes[name] = votes.get(name, 0) + 1

rating = sorted(votes.items(), key=lambda pair: pair[1], reverse=True)
winner = rating[0][0]

for name, n in rating:
    print(name.ljust(30), n)           # ljust — выровнять по ширине 30

9. То же через Counter

Counter из collections — словарь-счётчик: отсутствующий ключ равен 0, а most_common() сразу даёт отсортированный рейтинг.

from collections import Counter

votes = Counter()
with open("elections.txt", encoding="utf8") as file:
    for line in file:
        if line.strip() in students:
            votes[line.strip()] += 1

rating = votes.most_common()    # [('Фамилия', 12), ...]
winner = rating[0][0]
