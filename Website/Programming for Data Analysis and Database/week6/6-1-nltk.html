NLTK: словари, токены, части речи

Для анализа текста в Python есть NLTK, TextBlob, spaCy, Gensim и TfidfVectorizer из scikit-learn. На этой неделе основная — NLTK. Ей сначала нужно скачать данные: словари и обученные модели.

2. WordNet: значения слова

synsets("car") — все значения слова «car». У каждого есть определение и иногда пример. Печатаем только те, где пример есть.

from nltk.corpus import wordnet

syns = wordnet.synsets("car")
for syn in syns:
    if syn.examples():
        print("Definition:", syn.definition())
        print("Examples:", syn.examples())
# Definition: a motor vehicle with four wheels; usually propelled by an internal combustion engine
# Examples: ['he needs a car to get to work']
# … ещё 3 значения: вагон поезда, кабина лифта, cable car

3. Токенизация: предложения и слова

sent_tokenize режет на предложения, word_tokenize — на слова. Знаки препинания становятся отдельными токенами. don't делится на do + n't.

from nltk.tokenize import sent_tokenize, word_tokenize

text = "Hello world. NLTK makes text processing easy!"
sent_tokenize(text)   # ['Hello world.', 'NLTK makes text processing easy!']
word_tokenize(text)   # ['Hello', 'world', '.', 'NLTK', 'makes', 'text', 'processing', 'easy', '!']

word_tokenize("Don't stop! It's 3.5 km, isn't it?")
# ['Do', "n't", 'stop', '!', 'It', "'s", '3.5', 'km', ',', 'is', "n't", 'it', '?']

4. Части речи: pos_tag

На вход — список токенов (даже если слово одно), на выход — пары (слово, тег). Тег нужен, чтобы лемматизация работала правильно: running-глагол → run.

text = nltk.word_tokenize("NLTK is a great library for text processing.")
nltk.pos_tag(text)
# [('NLTK', 'NNP'), ('is', 'VBZ'), ('a', 'DT'), ('great', 'JJ'), ('library', 'NN'),
#  ('for', 'IN'), ('text', 'NN'), ('processing', 'NN'), ('.', '.')]

5. Стоп-слова

Список английских стоп-слов NLTK — 198 слов (русских 151, казахских 324). Делаем set — проверка «есть ли слово» в множестве мгновенная. Список в нижнем регистре, поэтому сравниваем w.lower().

from nltk.corpus import stopwords

stop_words = set(stopwords.words('english'))
words = ["this", "is", "a", "sample", "sentence"]
filtered = [w for w in words if w.lower() not in stop_words]
print(filtered)   # ['sample', 'sentence']

# наоборот — найти сами стоп-слова в токенах из шага 4

stopwords.words('russian')    # 151 слово
stopwords.words('kazakh')     # 324 слова

6. Свой список стоп-слов

Если готового списка нет или он не подходит — пишем свой set. Тут текст делится простым split(), поэтому знаки остаются приклеенными к словам (көрсетеді.).

kazakh_stop_words = set(['және', 'мен', 'не', 'бір', 'ол', 'бұл', 'соң', 'болды',
                         'үшін', 'сол', 'қалай', 'барлық', 'қашан', 'қайда',
                         'сондай', 'осы', 'менің'])

text3 = "Бұл қазақ тіліндегі сөйлем, және ол стоп-словтарды алып тастауды көрсетеді."
[word for word in text3.split() if word.lower() not in kazakh_stop_words]
# ['қазақ', 'тіліндегі', 'сөйлем,', 'стоп-словтарды', 'алып', 'тастауды', 'көрсетеді.']
