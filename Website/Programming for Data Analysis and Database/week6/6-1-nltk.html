Как компьютер читает текст: токены, теги, стоп-слова

Для Python предложение — просто строка символов. Он не знает, где кончается слово, что «students» и «student» — одно и то же, а «the» ничего не значит. NLP (Natural Language Processing, обработка естественного языка) — это набор приёмов, которые разбирают текст на части, чтобы его можно было считать и анализировать.

Сначала слова: что как называется

Все термины этой недели на одном примере — предложение The students quickly finished their difficult assignments.

ТокенКусочек текста, с которым дальше работаем: обычно слово или знак препинания. Как «кирпичик» текста.'students', 'finished', '.'
ТокенизацияРазрезать текст на токены. Можно резать на предложения (sentence tokenization) или на слова (word tokenization)."Hi. Bye!" → ['Hi.', 'Bye!']
Часть речи (POS)Какую роль слово играет: существительное, глагол, прилагательное, наречие… POS = Part of Speech.students — сущ., finished — глагол
Тег (POS-тег)Короткий код части речи, который ставит NLTK. Это не слово, а метка-ярлык. Буква в начале — сама часть речи, остальное — уточнение.NNS = сущ. во мн. ч., VBD = глагол в прошедшем
Стоп-словоОчень частое служебное слово, которое почти не несёт смысла: артикли, предлоги, местоимения, «быть». Их выкидывают, чтобы они не забивали подсчёты.the, is, a, their, и, но, как
ЛеммаСловарная (начальная) форма слова — как его записали бы в словаре. Приводим к ней, чтобы разные формы считались одним словом.students → student, finished → finish
Синоним и синсетСинонимы — слова с одним значением. Синсет (synset = synonym set) — группа синонимов для одного значения слова в словаре WordNet.car, auto, automobile, motorcar
Корпус / ресурсГотовые данные, которые NLTK скачивает отдельно: словари, списки слов, обученные модели. Без них функции не работают.stopwords, wordnet, punkt

Весь путь на одном предложении

Так выглядит подготовка текста. На этой странице — шаги 1–3, леммы и очистка — на следующей.

Исходный текстпросто строка

Было 8 токенов — осталось 5 значимых слов в начальной форме. С такими словами уже можно считать частоты, искать ключевые слова, определять тональность.

1. Установить NLTK и скачать ресурсы

Что это. NLTK (Natural Language Toolkit) — самая известная библиотека Python для работы с текстом. Есть и другие: TextBlob, spaCy, Gensim, TfidfVectorizer из scikit-learn — они будут дальше.

Зачем download. pip install nltk ставит только код. Словари и обученные модели весят много, поэтому скачиваются отдельно командой nltk.download(...) — один раз, потом лежат на диске. Если забыть, будет ошибка Resource ... not found.

!pip install nltk
import nltk

nltk.download('wordnet')                          # словарь английского языка
nltk.download('averaged_perceptron_tagger_eng')   # модель, которая ставит теги
nltk.download('stopwords')                        # списки стоп-слов
nltk.download('punkt')                            # модель, которая режет на предложения и слова
nltk.download('punkt_tab')                        # она же в новом формате
wordnetБольшой словарь английского. Слова сгруппированы по значениям (синсеты). Нужен, чтобы находить синонимы и лемму слова.
perceptron taggerОбученная модель (перцептрон — простая нейросеть). Смотрит на слово и соседей и угадывает часть речи.
stopwordsГотовые списки стоп-слов для разных языков: английский, русский, казахский и др.
punktМодель, которая знает, где кончается предложение: что точка в «3.5» или «Dr.» — не конец.

2. WordNet: значения и синонимы слова

Что это. У одного слова бывает несколько значений: «car» — это и машина, и вагон поезда, и кабина лифта. WordNet хранит каждое значение отдельно — это и есть синсет. У синсета есть определение, примеры и список синонимов.

Как читать код. synsets("car") — все значения слова (их 5). Цикл идёт по ним, и если у значения есть пример (syn.examples() не пустой), печатает определение и пример.

from nltk.corpus import wordnet

syns = wordnet.synsets("car")        # 5 значений: car.n.01 … cable_car.n.01
for syn in syns:
    if syn.examples():
        print("Definition:", syn.definition())
        print("Examples:", syn.examples())
# Definition: a motor vehicle with four wheels; usually propelled by an internal combustion engine
# Examples: ['he needs a car to get to work']
# … дальше вагон поезда, кабина лифта, cable car

syns[0].lemma_names()   # ['car', 'auto', 'automobile', 'machine', 'motorcar'] — синонимы

Как читать car.n.01: слово car, часть речи n (noun — существительное), значение номер 01.

3. Токенизация: разрезать текст

Что это. Разбить текст на предложения (sent_tokenize) или на слова (word_tokenize). Результат — список строк.

Почему не просто split(). "easy!".split() оставит знак приклеенным к слову, и «easy!» и «easy» посчитаются разными словами. word_tokenize отделяет знаки в отдельные токены, понимает сокращения (don't → do + n't) и не режет числа вроде 3.5.

from nltk.tokenize import sent_tokenize, word_tokenize

text = "Hello world. NLTK makes text processing easy!"
sent_tokenize(text)   # ['Hello world.', 'NLTK makes text processing easy!']        — 2 предложения
word_tokenize(text)   # ['Hello', 'world', '.', 'NLTK', 'makes', 'text', 'processing', 'easy', '!']

word_tokenize("Don't stop! It's 3.5 km, isn't it?")
# ['Do', "n't", 'stop', '!', 'It', "'s", '3.5', 'km', ',', 'is', "n't", 'it', '?']

4. Части речи: pos_tag ставит теги

Что это. Для каждого токена определить часть речи. NLTK пишет её не словом, а коротким кодом — тегом. Теги взяты из стандартного набора Penn Treebank, их около 36, но нужны в основном эти:

тегчто значитпример
NNсуществительное, ед. числоlibrary, text
NNSсуществительное, мн. число (S = plural)students, streets
NNPимя собственное (P = proper)NLTK, Astana
VBглагол, начальная формаrun, be
VBDглагол, прошедшее время (D = past)finished, was
VBGглагол на -ingrunning
VBZглагол, он/она/оно сейчасis, makes
JJприлагательноеgreat, difficult
RBнаречиеquickly, soon
DTартикль / определительthe, a
INпредлог или союзfor, in, because
PRP, PRP$местоимение / притяжательноеhe, I / their, our

Как запомнить: важна первая буква — N существительное, V глагол, J прилагательное, R наречие. Зачем теги: чтобы правильно найти лемму (на следующей странице). «leaves» как существительное → leaf (лист), как глагол → leave (уходить).
Важно: pos_tag принимает список токенов, а не строку — поэтому сначала word_tokenize.

text = nltk.word_tokenize("NLTK is a great library for text processing.")
nltk.pos_tag(text)
# [('NLTK', 'NNP'), ('is', 'VBZ'), ('a', 'DT'), ('great', 'JJ'), ('library', 'NN'),
#  ('for', 'IN'), ('text', 'NN'), ('processing', 'NN'), ('.', '.')]
Читаем результат: каждая пара — (слово, тег).
  • ('NLTK', 'NNP') — имя собственное (название библиотеки)
  • ('is', 'VBZ') — глагол «быть», он/она/оно
  • ('great', 'JJ') — прилагательное
  • ('.', '.') — у знаков препинания тег — сам знак

Попробуй: разбор предложения

Выбери предложение. Под каждым словом — тег от nltk.pos_tag (посчитано настоящим NLTK). Цвет — часть речи: синий сущ., красный глагол, зелёный прилаг., оранжевый наречие. Наведи на слово — расшифровка.

5. Стоп-слова: выкинуть «мусор»

Что это. Стоп-слова — самые частые слова языка, которые нужны для грамматики, но почти не говорят, о чём текст: the, a, is, of, their, и, в, не. Если посчитать частоты слов в любой статье, наверху всегда будут они — а это бесполезно.

Как работает. У NLTK есть готовый список: английский — 198 слов, русский — 151, казахский — 324. Превращаем список в set (множество) — проверка «есть ли слово» в множестве мгновенная. Слова в списке маленькими буквами, поэтому сравниваем w.lower(): иначе «The» не узнается.
Осторожно: в списке есть not и no. Для анализа тональности их выкидывать нельзя — «not good» превратится в «good».

from nltk.corpus import stopwords

stop_words = set(stopwords.words('english'))      # 198 слов
words = ["this", "is", "a", "sample", "sentence"]
filtered = [w for w in words if w.lower() not in stop_words]
print(filtered)   # ['sample', 'sentence'] — остались только слова со смыслом

# наоборот: какие стоп-слова были в предложении из шага 4
[w for w in text if w.lower() in stop_words]   # ['is', 'a', 'for']

stopwords.words('russian')    # 151 слово: и, в, во, не, что, он, на, я …
stopwords.words('kazakh')     # 324 слова

Как читать [w for w in words if w.lower() not in stop_words]: «пройди по каждому слову w и оставь его, если его нет в списке стоп-слов». Это list comprehension — короткая запись цикла с условием.

6. Свой список стоп-слов

Зачем. Готовый список может не подойти: например, в отзывах о курсах слово «course» есть везде и ничего не различает — его можно добавить. Или для языка нет хорошего списка. Тогда пишем свой set.

Здесь текст режется простым split() (по пробелам), поэтому знаки остались приклеенными: сөйлем, и көрсетеді.. Слова Бұл, және, ол выкинуты — они в списке.

kazakh_stop_words = set(['және', 'мен', 'не', 'бір', 'ол', 'бұл', 'соң', 'болды',
                         'үшін', 'сол', 'қалай', 'барлық', 'қашан', 'қайда',
                         'сондай', 'осы', 'менің'])

text3 = "Бұл қазақ тіліндегі сөйлем, және ол стоп-словтарды алып тастауды көрсетеді."
[word for word in text3.split() if word.lower() not in kazakh_stop_words]
# ['қазақ', 'тіліндегі', 'сөйлем,', 'стоп-словтарды', 'алып', 'тастауды', 'көрсетеді.']
