Тональность текста: позитив, негатив, нейтрально

Три готовых словаря (TextBlob, VADER в двух видах) и один свой классификатор (TF-IDF + SVM). Это прямая подготовка к Assignment 3, задание 1.

Сначала слова: что как называется

Тональность (sentiment)Эмоциональная окраска текста: положительная, отрицательная или нейтральная. Анализ тональности — определить её автоматически."I love it" → Positive
Полярность (polarity)Тональность числом от −1 до 1: −1 очень негативно, 0 нейтрально, 1 очень позитивно.0.625
ПорогГраница, после которой число превращается в метку. Выше порога — Positive, ниже минус порога — Negative, между — Neutral.±0.05 у VADER
Словарный метод (лексикон)Есть готовый словарь «слово → оценка эмоции». Оценки слов текста складываются. Ничего обучать не надо, но работает только для языка словаря.love +3.2, boring −1.3
VADER и compoundСловарный метод для соцсетей. Выдаёт доли neg / neu / pos и итоговое число compound от −1 до 1 — по нему и решают.compound 0.67 → Positive
Размеченные данныеПримеры, где правильный ответ уже проставлен человеком. На них учится модель.("awful experience", 0)
TF-IDFПревращает текст в набор чисел (вектор): вес каждого слова. Вес выше, если слово частое в этом тексте и редкое в остальных.30 фраз → таблица 30 × 105
Классификатор, SVMМодель, которая относит объект к классу (позитив / негатив). SVM ищет границу, которая лучше всего разделяет два класса.svm.SVC(kernel='linear')
accuracy, precision, recallaccuracy — доля верных ответов. precision — из тех, кого модель назвала «позитив», сколько правда позитив. recall — из всех настоящих позитивов сколько она нашла.accuracy 4 из 6 = 0.67

1. TextBlob: polarity

TextBlob(text).sentiment.polarity — число от −1 (очень негативно) до 1 (очень позитивно), 0 — нейтрально. Порог ±0.01 превращает число в метку. TextBlob понимает только английский: для русского — spaCy (ru_core_news_sm) или Polyglot, для казахского — Stanza.

from textblob import TextBlob

def determine_sentiment(text):
    text_analysis = TextBlob(text)
    if text_analysis.sentiment.polarity > 0.01:
        return "Positive"
    elif text_analysis.sentiment.polarity < -0.01:
        return "Negative"
    else:
        return "Neutral"

sentence = input("Enter a sentence for analysis: ")
print(f"Sentence sentiment: {determine_sentiment(sentence)}")
# "I love this course!" → polarity 0.625 → Positive

2. VADER (vaderSentiment + spaCy)

VADER — словарь, сделанный для соцсетей: учитывает сленг, эмодзи, КАПС, «!!!», усилители («very») и отрицания («not»). Главное число — compound от −1 до 1, порог ±0.05. spaCy в этом коде только загружает модель и разбирает текст — на результат он не влияет, считает VADER.

!pip install spacy vaderSentiment
import spacy
from vaderSentiment.vaderSentiment import SentimentIntensityAnalyzer

nlp = spacy.load("en_core_web_sm")       # английская модель spaCy
analyzer = SentimentIntensityAnalyzer()

def determine_sentiment(text):
    doc = nlp(text)
    sentiment = analyzer.polarity_scores(text)
    if sentiment['compound'] >= 0.05:
        return "Positive"
    elif sentiment['compound'] <= -0.05:
        return "Negative"
    else:
        return "Neutral"

3. VADER внутри NLTK

Тот же VADER, встроен в NLTK — нужен только vader_lexicon. polarity_scores возвращает 4 числа: neg, neu, pos — доли (в сумме ≈ 1) и compound — итог. Версия в NLTK чуть старее: эмодзи не понимает, поэтому на «GREAT!!! 😀» compound 0.772, а у vaderSentiment 0.849.

import nltk
from nltk.sentiment.vader import SentimentIntensityAnalyzer
nltk.download('vader_lexicon')

analyzer = SentimentIntensityAnalyzer()
analyzer.polarity_scores("I love this course!")
# {'neg': 0.0, 'neu': 0.308, 'pos': 0.692, 'compound': 0.6696}

4. Свой классификатор: TF-IDF + SVM

TfidfVectorizer превращает каждый текст в вектор чисел: вес слова растёт, если оно частое в этом тексте, и падает, если встречается во многих текстах. Сам тональность не знает — нужна модель, обученная на размеченных примерах (1 — позитив, 0 — негатив). Тут SVM с линейным ядром. В ноутбуке 30 фраз, test_size=0.2 → в тест попадает 6.

from sklearn.feature_extraction.text import TfidfVectorizer
from sklearn import svm
from sklearn.model_selection import train_test_split
from sklearn.metrics import accuracy_score, classification_report

data = [("I love this product, it's amazing!", 1),
        ("I had an awful experience.", 0),
        # … всего 30 фраз: 15 позитивных, 15 негативных
       ]
texts  = [item[0] for item in data]
labels = [item[1] for item in data]

vectorizer = TfidfVectorizer()
X = vectorizer.fit_transform(texts)          # (30, 105): 30 фраз × 105 разных слов

X_train, X_test, y_train, y_test = train_test_split(X, labels, test_size=0.2, random_state=42)

model = svm.SVC(kernel='linear')
model.fit(X_train, y_train)
y_pred = model.predict(X_test)

accuracy_score(y_test, y_pred)               # 0.667 → "Model accuracy: 66.67%"
print(classification_report(y_test, y_pred))
# класс 0: precision 0.60, recall 1.00 · класс 1: precision 1.00, recall 0.33

new_text_vectorized = vectorizer.transform(["The product exceeded all my expectations"])
model.predict(new_text_vectorized)           # [1] → Positive (эта фраза была в обучении)

Почему всего 67%: 24 фразы на обучение — очень мало, модель видит лишь сотню слов. Из 3 позитивных в тесте угадала 1 (recall 0.33). random_state=42 — фиксирует перемешивание, чтобы результат повторялся; 42 — шутка из «Автостопом по галактике», можно любое число.
