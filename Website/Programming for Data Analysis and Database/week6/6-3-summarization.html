1. Предобработка всей статьи

Как на прошлой странице: токены → без стоп-слов → лемма по части речи → нижний регистр → предложения → без знаков. get_wordnet_pos — то же сопоставление тегов, но функцией: первая буква тега → 'a' / 'n' / 'v' / 'r', иначе существительное.

import nltk, string
from nltk import word_tokenize, sent_tokenize
from nltk.corpus import wordnet, stopwords
from nltk.stem import WordNetLemmatizer

with open('article2.txt', encoding='utf8') as file:
    text = file.read()

def get_wordnet_pos(word):
    tag = nltk.pos_tag([word])[0][1][0].upper()
    tag_dict = {"J": wordnet.ADJ, "N": wordnet.NOUN, "V": wordnet.VERB, "R": wordnet.ADV}
    return tag_dict.get(tag, wordnet.NOUN)

text_list = word_tokenize(text)
stop_words = stopwords.words('english')
text_list = [word for word in text_list if word not in stop_words]

lemma_function = WordNetLemmatizer()
text1 = ' '.join([lemma_function.lemmatize(w, get_wordnet_pos(w)) for w in text_list])
text1 = text1.lower()

text_sent = sent_tokenize(text1)              # 36 предложений
for p in string.punctuation:                  # убрать знаки в каждом предложении
    for i in range(len(text_sent)):
        text_sent[i] = text_sent[i].replace(p, '')

preprocessed_text = ' '.join(text_sent)

2. Самые частые слова

FreqDist из NLTK и Counter из Python делают одно: считают, сколько раз встретилось каждое слово. most_common(n) — топ-n. Частые слова и есть тема статьи.

from nltk.probability import FreqDist
from collections import Counter

word_preprocessed_text = word_tokenize(preprocessed_text)

fdist = FreqDist(word_preprocessed_text)
[word for word, freq in fdist.most_common(6)]
# ['melody', 'search', 'similarity', 'plagiarism', 'system', 'similar']

Counter(word_preprocessed_text).most_common(10)
# [('melody', 28), ('search', 14), ('similarity', 10), ('plagiarism', 9), ('system', 8), …]

3. Биграммы и условная вероятность

Биграмма — пара соседних слов. Вероятность, что после слова A идёт B: P(B | A) = count(A, B) / count(A, …). Пример: plagiarism встречается первым в 9 парах, из них 6 раз — plagiarism detection, значит P = 6/9 = 0.667.

from nltk.util import ngrams

bigrams = list(ngrams(word_preprocessed_text, 2))
frequency = Counter(bigrams)                                  # сколько раз каждая пара
first_word_count = Counter([bigram[0] for bigram in bigrams]) # сколько раз слово стоит первым

conditional_probabilities = {
    bigram: count / first_word_count[bigram[0]]
    for bigram, count in frequency.items()
}
# ('plagiarism', 'detection'): 0.667 · ('melody', 'sequence'): 0.25 · ('melody', 'search'): 0.143

4. Оценка предложений

Вероятность предложения = произведение вероятностей его биграмм. Сортируем, берём первые 5. Важно: в ноутбуке append стоит внутри цикла по биграммам — получается 429 чисел вместо 36, и они не совпадают с предложениями. Правильно — один append на предложение, после внутреннего цикла (код ниже уже исправлен). И ещё: произведение чисел меньше 1 тем меньше, чем длиннее предложение, — поэтому метод любит короткие предложения («This paper is organized as follows.»).

sentences_probability = []
for i in range(len(text_sent)):
    sentence_bigrams = list(ngrams(word_tokenize(text_sent[i]), 2))
    sentence_probability = 1.0
    for bigram in sentence_bigrams:
        if bigram in conditional_probabilities:
            sentence_probability *= conditional_probabilities[bigram]
    sentences_probability.append(sentence_probability)   # ← после цикла, не внутри

the_dict = {text: probability
            for text, probability in zip(sent_tokenize(text), sentences_probability)}
the_dict = sorted(the_dict.items(), key=lambda pair: pair[1], reverse=True)

for i, j in the_dict[:5]:
    print(i)
# 1. Without realizing it, any composers may be involved in diverse plagiarism disputes.  (0.222)
# 2. This paper is organized as follows.  (0.167)

5. sumy: TextRank, Luhn, LSA

Готовые алгоритмы, вторым аргументом — сколько предложений оставить. TextRank — как PageRank: предложение важно, если похоже на много других. Luhn — ищет предложения, где плотно стоят значимые частые слова. LSA — раскладывает матрицу «слова × предложения» (SVD) на скрытые темы и берёт по предложению на тему.

from sumy.parsers.plaintext import PlaintextParser
from sumy.nlp.tokenizers import Tokenizer
from sumy.summarizers.text_rank import TextRankSummarizer
from sumy.summarizers.luhn import LuhnSummarizer
from sumy.summarizers.lsa import LsaSummarizer

parser = PlaintextParser.from_string(text, Tokenizer("english"))

summarizer = TextRankSummarizer()
summary = summarizer(parser.document, 2)       # 2 предложения
text_summary = ""
for sentence in summary:
    text_summary += str(sentence)

for sentence in LuhnSummarizer()(parser.document, 2):
    print(sentence)

lsa_summary = "".join(str(s) for s in LsaSummarizer()(parser.document, 2))
