Очистка текста: regex → токены → стоп-слова → леммы

Перед анализом текст готовят по шагам: убрать знаки и числа, нижний регистр, разбить на слова, выкинуть стоп-слова, привести слова к начальной форме.

Сначала слова: что как называется

Токен, тег и стоп-слово — на предыдущей странице. Здесь добавляются:

Регулярное выражение (regex)Шаблон для поиска кусков текста. Не конкретное слово, а правило: «любая цифра», «всё, что не буква». Модуль Python — re.\d+ → все числа в тексте
Очистка (предобработка)Привести текст к одному виду перед анализом: убрать знаки и числа, сделать все буквы маленькими, выкинуть стоп-слова."Day!" и "day" → "day"
ЛемматизацияПривести слово к словарной форме (лемме) по словарю WordNet. Результат — настоящее слово. Нужно знать часть речи.studies → study, was → be, feet → foot
СтеммингГрубо отрезать окончание по правилам, без словаря. Быстро, но часто получается не-слово. Основа слова = stem.studies → studi, beautiful → beauti
Зачем это всёЧтобы «study», «studies», «studying» считались одним словом. Иначе частоты и модели «размазываются» по формам.3 формы → 1 слово

1. re.sub — убрать знаки препинания

Что делает re.sub(шаблон, замена, текст): находит в тексте всё, что подходит под шаблон, и заменяет на «замену». Замена '' — пустая строка, то есть «удалить». re.findall — не заменяет, а возвращает список найденного.

Регулярное выражение — шаблон поиска. [...] — набор символов, ^ внутри — «НЕ», \w — буква / цифра / _, \s — пробел, таб, перенос. Значит [^\w\s] — всё, что не буква и не пробел, то есть знаки. r'' — «сырая» строка, чтобы \ не съел Python.

import re

text = "Life, believe, is not a dream.\n So dark as sages say;\n Oft a little morning rain \n Foretells a pleasant day!"
text1 = re.sub(r'[^\w\s]', '', text)
# 'Life believe is not a dream\n So dark as sages say\n Oft a little morning rain \n Foretells a pleasant day'

re.findall(r'sa', text, re.I)                  # ['sa', 'sa', 'sa']  — re.I: без учёта регистра
re.sub(r'sa', '*' * 2, text, flags=re.I)       # '… So dark as **ges **y; … plea**nt day!'

2. То же циклом (и почему regex удобнее)

Перебираем каждый символ и каждый знак из списка, совпал — replace на пустоту. Работает, но два вложенных цикла. Regex делает то же одной строкой. Обратите внимание: & убран, а двойной пробел остался.

inp_str = "Hello? Folks, we are here to learn & improve!@!"
marks = "!()-[]{};?@#$%:'\,./^&;*_"

opt_str = inp_str
for x in inp_str:
    for i in marks:
        if x == i:
            opt_str = opt_str.replace(x, "")
# 'Hello Folks we are here to learn  improve'

re.sub(r"[!()\[\]{};?@#$%:'\\,./^&;*_]", '', inp_str)   # тот же результат

3. Конвейер: нижний регистр → токены → только буквы → без стоп-слов

Стоп-слова NLTK записаны маленькими буквами. Если не сделать lower(), So не выкинется (а so — да). isalpha() оставляет только токены из букв — так уходят знаки.

from nltk.corpus import stopwords
from nltk.tokenize import word_tokenize

# без lower(): знаки и "So" остались
[w for w in word_tokenize(text) if not w in stopwords.words('english')]
# ['Life', ',', 'believe', ',', 'dream', '.', 'So', 'dark', 'sages', 'say', ';', 'Oft', …]

text = text.lower()
words = word_tokenize(text)
words = [word for word in words if word.isalpha()]
stop_words = set(stopwords.words('english'))
words = [word for word in words if word not in stop_words]
# ['life', 'believe', 'dream', 'dark', 'sages', 'say', 'oft', 'little',
#  'morning', 'rain', 'foretells', 'pleasant', 'day']

4. Лемматизация

Лемма — словарная форма: sages → sage. Без подсказки лемматизатор считает каждое слово существительным, поэтому foretells не изменился. Нужна часть речи: pos_tag даёт теги JJ / VB… / RB / NN…, а lemmatize ждёт 'a' / 'v' / 'r' / 'n'. tag_map переводит первую букву тега. defaultdict — словарь, который для незнакомого ключа сам вернёт значение по умолчанию (тут — существительное) вместо KeyError.

from nltk.stem import WordNetLemmatizer
lemmatizer = WordNetLemmatizer()
' '.join([lemmatizer.lemmatize(w) for w in words])
# 'life believe dream dark sage say oft little morning rain foretells pleasant day'

from nltk.corpus import wordnet as wn
from nltk import word_tokenize, pos_tag
from collections import defaultdict

tag_map = defaultdict(lambda: wn.NOUN)   # всё незнакомое → существительное
tag_map['J'] = wn.ADJ
tag_map['V'] = wn.VERB
tag_map['R'] = wn.ADV

text = "Yesterday he was in the most beautiful buildings on our streets."
for w, tag in pos_tag(word_tokenize(text)):
    print(w, "=>", lemmatizer.lemmatize(w, tag_map[tag[0]]), "=>", tag)
# was => be (VBD) · buildings => building (NNS) · streets => street (NNS)

5. Стемминг против лемматизации

Стеммер (Porter) просто отрезает окончания — быстро, но получаются не-слова: studi, beauti. Лемматизатор смотрит в словарь и возвращает настоящее слово, если знает часть речи. Для признаков ML лемматизация обычно лучше.

from nltk.stem import PorterStemmer

ps = PorterStemmer()
for w in ["program", "programs", "programmer", "programming", "programmers"]:
    print(w, " : ", ps.stem(w))
# program · program · programm · program · programm
