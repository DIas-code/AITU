Неделя 3 · Лекция 3.3

Пример: онлайн-курсы и оценки

20 пользователей × 12 курсов. Матрица оценок R: 0 — не проходил, 1…5 — оценка. Весь анализ — только средствами NumPy.

1. Создать матрицу и подписи

int8 — оценки маленькие, хватает одного байта. Отдельно массивы с номерами пользователей и названиями курсов, чтобы потом выводить понятные ответы.

import numpy as np

n_users, n_items = 20, 12
R = np.zeros((n_users, n_items), dtype=np.int8)   # (20, 12), всё нули

users = np.arange(1, n_users + 1)                 # [1 ... 20]
courses = np.array(["Python Basics", "Data Analysis", "SQL", "ML Intro",
                    "Deep Learning", "NLP", "Computer Vision", "Cloud",
                    "Cybersecurity", "Project Mgmt", "DevOps", "GIS"], dtype=object)

2. Заполнить случайными оценками

default_rng(42) — генератор с фиксированным seed. Берём 200 случайных пар (пользователь, курс) и одним присваиванием ставим им оценки: это индексация массивами.

rng = np.random.default_rng(42)
m = 200
u_idx = rng.integers(0, n_users, size=m)   # 200 случайных строк
i_idx = rng.integers(0, n_items, size=m)   # 200 случайных столбцов
ratings = rng.integers(1, 6, size=m)       # оценки 1..5 (6 не входит)

R[u_idx, i_idx] = ratings                  # повтор пары — перезапишется

R[:5, :3] = rng.integers(1, 6, size=(5, 3))   # заполнить угол срезом

3. Сохранить и загрузить

.npy — родной формат NumPy: сохраняет форму и тип. array_equal проверяет, что загрузилось то же самое.

np.save("ratings.npy", R)
R2 = np.load("ratings.npy")
np.array_equal(R, R2)   # True

4. Прочитать и изменить оценки

Люди считают с 1, NumPy — с 0. Поэтому пользователь 10 — это строка 9. Строка — все оценки пользователя, столбец — все оценки курса.

u, c = 10, 3
ui, ci = u - 1, c - 1     # перевод в индексы с нуля

R[ui, ci]     # оценка пользователя 10 за курс 3
R[ui, :]      # все оценки пользователя 10
R[:, ci]      # все оценки курса 3

R[ui, ci] = 5          # пользователь 10 поставил 5
R[7 - 1, 2 - 1] = 0    # пользователь 7 удалил оценку курса 2

5. Поднять оценки курса на 1, но не выше 5

Маска col0 > 0 выбирает только тех, кто проходил курс — нули трогать нельзя. np.clip не даёт выйти за 5.

col0 = R[:, 0]
taken0 = col0 > 0                                   # True там, где есть оценка
col0[taken0] = np.clip(col0[taken0] + 1, 1, 5)
R[:, 0] = col0

6. Маски: кто что прошёл

Сравнение даёт массив True/False. Сумма маски = количество True. axis=1 — по строкам (на пользователя), axis=0 — по столбцам (на курс).

x = np.array([1, 5, 8, 2, 0])
x[x > 2]                          # [5 8] — фильтр маской

taken = R > 0
courses_per_user = taken.sum(axis=1)   # сколько курсов у каждого
users_per_course = taken.sum(axis=0)   # сколько людей на каждом курсе

# какие курсы прошёл пользователь 10
idx = np.nonzero(R[ui, :])[0]          # индексы ненулевых
courses[idx]                           # их названия

7. Доля высоких оценок без деления на ноль

& — «и» для масок. np.divide(..., where=...) делит только там, где знаменатель больше нуля, а в остальных местах оставляет 0 из out.

high = R >= 4
high_count  = (high & taken).sum(axis=0)
taken_count = taken.sum(axis=0)

high_share = np.divide(high_count, taken_count,
                       out=np.zeros_like(high_count, dtype=float),
                       where=taken_count > 0)

8. Средние без нулей: два способа

Нули — это «не проходил», а не оценка 0, их нельзя усреднять. Способ A: заменить 0 на NaN и взять nanmean. Способ B: сумма ÷ количество по маске. Результаты совпадают.

# A) через NaN
R_nan = R.astype(np.float32).copy()
R_nan[R_nan == 0] = np.nan
mean_course = np.nanmean(R_nan, axis=0)
mean_user   = np.nanmean(R_nan, axis=1)

# B) сумма / количество
cnt = taken.sum(axis=0)
mean_course_b = np.divide(R.sum(axis=0), cnt,
                          out=np.zeros(n_items), where=cnt > 0)

courses[mean_course >= 3]                        # курсы со средним ≥ 3
users[np.where(courses_per_user >= 8)[0]]        # у кого ≥ 8 курсов
courses[np.argsort(mean_course_b)[-3:][::-1]]    # топ-3 по средней
courses[np.argmax(users_per_course)]             # самый популярный

9. Центрирование по пользователю

Один всегда ставит 5, другой строже. Вычитаем из оценок человека его среднее: 0 — «как обычно», плюс — нравится больше, минус — меньше. mean_u[:, None] делает из вектора столбец, чтобы сработал broadcasting.

mean_u = mean_user.astype(np.float32)             # (20,)
R_centered = R.astype(np.float32) - mean_u[:, None]  # (20,12) - (20,1)
R_centered[~taken] = 0.0                          # ~ — «не»: пропуски оставить 0

# Пример: оценки [5, 4, 5], среднее 4.67 → [0.33, -0.67, 0.33]

10. Стандартизация по курсу (z-score)

z = (оценка − среднее курса) / std курса. После этого у каждого курса среднее 0 и разброс 1 — курсы можно сравнивать. Если std = 0, делим на 1, чтобы не получить деление на ноль.

Rf = R.astype(np.float32)
cnt = taken.sum(axis=0)

mean_i = np.divide(np.where(taken, Rf, 0).sum(axis=0), cnt,
                   out=np.zeros(n_items, dtype=np.float32), where=cnt > 0)

diff2 = (Rf - mean_i[None, :]) ** 2
diff2[~taken] = 0
std_i = np.sqrt(np.divide(diff2.sum(axis=0), cnt,
                          out=np.zeros(n_items, dtype=np.float32), where=cnt > 0))

std_safe = np.where(std_i < 1e-8, 1.0, std_i)     # защита от std = 0
R_z = (Rf - mean_i[None, :]) / std_safe[None, :]
R_z[~taken] = 0.0
# проверка: по каждому курсу среднее ≈ 0, std ≈ 1
