Картинка как массив NumPy

Фотография — это просто массив чисел. Обрезать, уменьшить, перевернуть, осветлить — всё делается срезами и арифметикой.

1. Загрузить картинку

plt.imread читает файл сразу в массив NumPy. Форма (высота, ширина, 3): у каждого пикселя три числа — красный, зелёный, синий, от 0 до 255.

import numpy as np
import matplotlib.pyplot as plt

image = plt.imread("street.jpg")
plt.imshow(image)
plt.axis("off")
plt.show()

image.shape   # (3000, 4000, 3) — 3000 строк, 4000 столбцов, 3 канала
image.size    # 36 000 000 чисел
image.dtype   # uint8 — целые от 0 до 255

2. Один пиксель

Индекс image[строка, столбец, канал]. Без канала получаешь все три цвета пикселя.

image[100, 200]       # [ 73  88 143] — R, G, B
image[100, 200, 0]    # 73  — только красный
image[100, 200, 2]    # 143 — только синий

3. Чёрно-белая версия

Среднее по оси каналов (axis=2) превращает три числа пикселя в одно — яркость. Для такой картинки нужно указать cmap="gray", иначе Matplotlib раскрасит её своей палитрой.

gray = image.mean(axis=2)          # (3000, 4000) — один канал

plt.figure(figsize=(10, 8))        # холст
plt.subplot(1, 2, 1)               # 1 ряд, 2 места, рисуем в 1-е
plt.imshow(gray)                   # палитра по умолчанию — цветная
plt.subplot(1, 2, 2)
plt.imshow(gray, cmap="gray")      # серая палитра
plt.show()

4. Сделать ярче

Прибавляем 40 ко всем пикселям. np.clip обрезает значения по границам 0…255, чтобы они не вышли за допустимый диапазон.

bright = np.clip(image + 40, 0, 255)
plt.imshow(bright)

5. Обрезать, уменьшить, перевернуть

Всё это — срезы. Шаг ::10 берёт каждый 10-й пиксель (картинка в 10 раз меньше), шаг ::-1 идёт с конца (переворот).

image[500:2000, 1200:3500]   # вырезать прямоугольник
image[1000:2000]             # полоса строк 1000–2000
image[:, 100:1200]           # полоса столбцов
image[:1500, :2000]          # левый верхний угол

small = image[::10, ::10]    # (300, 400, 3) — уменьшили в 10 раз
flipped = image[::-1, :]     # вверх ногами

6. Разделить на каналы RGB

Каждый канал — отдельная матрица 3000×4000. Показываем их рядом, каждую в своём цвете.

red   = image[:, :, 0]
green = image[:, :, 1]
blue  = image[:, :, 2]

fig, axes = plt.subplots(1, 3, figsize=(12, 4))
axes[0].imshow(red, cmap="Reds")
axes[1].imshow(green, cmap="Greens")
axes[2].imshow(blue, cmap="Blues")
plt.show()

7. Изменить пиксели

Сначала copy(), иначе испортишь оригинал: срез в NumPy ссылается на те же данные.

modified = image.copy()
modified[500:1000, 1000:2000] = 255   # белый прямоугольник
plt.imshow(modified)

8. Нормализация 0…1

Нейросети работают с дробными числами в диапазоне 0…1, а не 0…255. Переводим в float32 и делим на 255.

normalized = image.astype(np.float32) / 255.0
normalized.min(), normalized.max()   # 0.0 1.0
normalized[1, 2]                     # [0.30 0.35 0.56]

9. Пачка картинок (batch)

Модель принимает не одну картинку, а пачку. expand_dims(axis=0) добавляет ось «номер картинки» спереди, np.stack собирает несколько картинок в одну пачку.

batch = np.expand_dims(normalized, axis=0)
batch.shape   # (1, 3000, 4000, 3) — 1 картинка, высота, ширина, каналы

# 32 картинки одного размера → одна пачка
from PIL import Image
images = []
for i in range(32):
    img = Image.open(f"images/image_{i}.jpg").resize((224, 224))
    images.append(np.array(img))
batch = np.stack(images)   # (32, 224, 224, 3)

# На практике пачки собирает DataLoader: 3200 картинок / 32 = 100 пачек за эпоху
