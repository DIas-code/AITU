Критерий χ² ПирсонаPearson's χ² test

\[ \chi^2=\sum \frac{(O_i-E_i)^2}{E_i} \]
Что этоWhat it is
Мера расхождения наблюдаемых частот с ожидаемыми.
A measure of how far observed frequencies are from expected ones.
Где используетсяWhere it is used
Таблицы сопряжённости: есть ли связь между двумя качественными признаками.
Contingency tables: is there an association between two categorical variables?
Как используетсяHow it is used
По каждой ячейке посчитать (O−E)²/E, всё сложить, сравнить с χ²_кр по df.
For each cell compute (O−E)²/E, sum them all, compare with χ²_crit at df.
ПримерExample
Пример из лекции (3×3, N = 170) → χ² = 34,98 при χ²_кр(0,05; 4) = 9,5 → связь значима.
Lecture example (3×3, N = 170) → χ² = 34.98 vs χ²_crit(0.05; 4) = 9.5 → significant.

Ожидаемая частотаExpected frequency

\[ E_{ij}=\frac{R_i\cdot C_j}{N} \]
Что этоWhat it is
Частота, которая была бы в ячейке при полном отсутствии связи.
The frequency a cell would have if there were no association at all.
Где используетсяWhere it is used
Первый шаг любого расчёта χ² — без E формулу не применить.
The first step of any χ² computation — without E the formula cannot be used.
Как используетсяHow it is used
R_i — итог строки, C_j — итог столбца, N — общий итог. Считается для каждой ячейки.
R_i is the row total, C_j the column total, N the grand total. Computed for every cell.
ПримерExample
30 × 73 / 170 = 12,88 ≈ 13 — совпадает с E, подписанным на слайде.
30 × 73 / 170 = 12.88 ≈ 13 — matches the E written on the slide.

Число степеней свободыDegrees of freedom

\[ df=(n_1-1)(n_2-1) \]
Что этоWhat it is
Параметр, по которому выбирается строка в таблице критических значений.
The parameter that selects the row in the table of critical values.
Где используетсяWhere it is used
Нужен сразу после расчёта χ², перед сравнением с таблицей.
Needed right after computing χ², before comparing with the table.
Как используетсяHow it is used
(число строк − 1) × (число столбцов − 1). Итоговые строка и столбец не считаются.
(rows − 1) × (columns − 1). Total row and column are not counted.
ПримерExample
Таблица 3×3 → df = 2 × 2 = 4 → χ²_кр(0,05) = 9,5.
A 3×3 table → df = 2 × 2 = 4 → χ²_crit(0.05) = 9.5.

Условия применения и выводAssumptions and conclusion

\[ E_{ij}>5\,,\qquad \chi^2>\chi^2_{\text{crit}} \]
Что этоWhat it is
Когда критерий вообще работает и как читать результат.
When the test is valid at all, and how to read the result.
Где используетсяWhere it is used
Проверять до расчёта: качественные данные, независимые группы, ожидаемая частота больше 5.
Check before computing: categorical data, independent groups, expected counts above 5.
Как используетсяHow it is used
Не применять при частоте в ячейке меньше 5, зависимых группах и абсолютных величинах (рост, вес, проценты).
Do not use with cell counts below 5, dependent groups, or continuous measures (height, weight, percentages).
ПримерExample
χ² = 34,98 > 9,5 → H₀ отвергаем: степень нарушения влияет на исход операции.
χ² = 34.98 > 9.5 → reject H₀: the severity level does affect the outcome.

Распределение χ²The χ² distribution

\[ \chi^2_n=\sum_{i=1}^{n} Z_i^2\,,\ \ Z_i\sim N(0,1)\,;\qquad M\chi^2_n=n\,,\qquad D\chi^2_n=2n \]
Что этоWhat it is
Сумма квадратов n независимых стандартных нормальных величин.
The sum of squares of n independent standard normal variables.
Где используетсяWhere it is used
Отсюда берутся критические значения в таблице.
This is where the table's critical values come from.
Как используетсяHow it is used
Параметр один — число степеней свободы n; при n > 2 мода равна n − 2.
A single parameter — the degrees of freedom n; for n > 2 the mode is n − 2.
ПримерExample
n = 4 → среднее 4, дисперсия 8, мода 2; асимметрия √(8/4) = 1,41.
n = 4 → mean 4, variance 8, mode 2; skewness √(8/4) = 1.41.

Плотность распределения χ²The χ² density function

\[ p_{\chi^2}(x)=\frac{x^{\,n/2-1}e^{-x/2}}{2^{\,n/2}\,\Gamma(n/2)}\,,\ x>0\,;\qquad p(x)=0\,,\ x\le 0 \]
Что этоWhat it is
Формула кривой, по которой вычисляются p-value.
The curve from which p-values are computed.
Где используетсяWhere it is used
Теоретическая часть; на практике берут готовую таблицу или калькулятор.
Theory only; in practice one uses a table or a calculator.
Как используетсяHow it is used
Γ(n/2) — гамма-функция. При n ≤ 2 кривая убывает, при n > 2 имеет максимум.
Γ(n/2) is the gamma function. For n ≤ 2 the curve decreases, for n > 2 it has a peak.
ПримерExample
При n → ∞ распределение приближается к нормальному со средним n и дисперсией 2n.
As n → ∞ the distribution approaches a normal one with mean n and variance 2n.

Гамма-распределение и связь с χ²The gamma distribution and its link to χ²

\[ f(x)=\frac{\lambda^r x^{r-1}e^{-\lambda x}}{\Gamma(r)}\,,\quad \Gamma(r)=\int_0^{\infty}x^{r-1}e^{-x}dx\,;\qquad \mu=\frac{r}{\lambda}\,,\quad \sigma^2=\frac{r}{\lambda^2} \]
Что этоWhat it is
Общее семейство распределений, частным случаем которого является χ².
The general family of distributions of which χ² is a special case.
Где используетсяWhere it is used
Объясняет, откуда взялась формула плотности χ².
Explains where the χ² density formula comes from.
Как используетсяHow it is used
Подставить λ = ½ и r = n/2 — получится ровно плотность χ² с n степенями свободы.
Substitute λ = ½ and r = n/2 — you get exactly the χ² density with n degrees of freedom.
ПримерExample
μ = r/λ = (n/2)/(½) = n, σ² = r/λ² = (n/2)/(¼) = 2n — совпадает с Mχ² и Dχ².
μ = r/λ = (n/2)/(½) = n, σ² = r/λ² = (n/2)/(¼) = 2n — matches Mχ² and Dχ².
