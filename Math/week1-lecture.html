Стандарты качества данныхData quality standards

  • Полнота — нет пропусков и неполных записей.
  • Точность — данные отражают реальность, без ошибок ввода.
  • Согласованность — единые форматы и единицы измерения.
  • Completeness — no gaps or incomplete records.
  • Accuracy — data reflect reality, no input errors.
  • Consistency — uniform formats and units.

Алгоритм выбора критерияHow to choose a test

  • Определить модель, подходящую для проверки предположения.
  • Прочитать описание метода, примеры и задачи.
  • Проверить ограничения критерия и возможность собрать данные.
  • Определить объём выборки и обеспечить к ней доступ.
  • Провести исследование и обработать данные по выбранному алгоритму.
  • Если ограничения не выполнены — вернуться на шаг назад.
  • Pick the model that fits the assumption being tested.
  • Read the method description, examples and exercises.
  • Check the test's restrictions and whether the data can be collected.
  • Determine the sample size and secure access to it.
  • Run the study and process the data using the chosen algorithm.
  • If the restrictions cannot be met — go back a step.
