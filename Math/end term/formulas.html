Манн–Уитни

Две независимые группы

Формулы

ЧтоФормула
РангиВсе значения обеих групп по возрастанию: 1, 2, 3, … Одинаковые — средний ранг их мест
U для группы 1\(U_1 = n_1 n_2 + \dfrac{n_1(n_1+1)}{2} - R_1\)
U для группы 2\(U_2 = n_1 n_2 + \dfrac{n_2(n_2+1)}{2} - R_2\)
Статистика\(U = \min(U_1,\ U_2)\)
Проверка 1\(R_1 + R_2 = \dfrac{N(N+1)}{2},\quad N = n_1 + n_2\)
Проверка 2\(U_1 + U_2 = n_1 n_2\)
Решение\(U \le U_{кр}\) → H₀ отвергаем (различие есть)  ·  \(U > U_{кр}\) → H₀ не отвергаем

2

Уилкоксон

Парные измерения (до / после)

Формулы

ЧтоФормула
Разность\(d_i = \text{Before}_i - \text{After}_i\); пары с \(d = 0\) выбрасываем, \(n\) уменьшается
РангиРанжируем \(|d_i|\) по возрастанию (одинаковые — средний ранг), потом возвращаем знак \(d_i\)
T⁺\(T^+ = \sum\) рангов, где \(d_i > 0\)
T⁻\(T^- = \sum\) рангов, где \(d_i < 0\)
Статистика\(T = \min(T^+,\ T^-)\)
Проверка\(T^+ + T^- = \dfrac{n(n+1)}{2}\)
Решение\(T \le T_{кр}\) → H₀ отвергаем (изменение есть)  ·  \(T > T_{кр}\) → H₀ не отвергаем

Тригонометрические формулы

Нужны для Лапласа от произведения

Произведение → сумма (главные для экзамена)

№ФормулаКогда
1\(2\sin A\cos B = \sin(A+B) + \sin(A-B)\)sin · cos
2\(2\cos A\sin B = \sin(A+B) - \sin(A-B)\)cos · sin
3\(2\cos A\cos B = \cos(A+B) + \cos(A-B)\)cos · cos
4\(2\sin A\sin B = \cos(A-B) - \cos(A+B)\)sin · sin
Знаки: \(\sin(-x) = -\sin x\) (нечётный), \(\cos(-x) = \cos x\) (чётный). Пример: \(\sin 2t\cos 5t = \tfrac12[\sin 7t + \sin(-3t)] = \tfrac12[\sin 7t - \sin 3t]\).

Ряд Фурье

Период 2L, отрезок [−L, L]
\[f(x) \sim \frac{a_0}{2} + \sum_{n=1}^{\infty}\left(a_n\cos\frac{n\pi x}{L} + b_n\sin\frac{n\pi x}{L}\right)\] \[a_0 = \frac1L\int_{-L}^{L} f(x)\,dx \qquad a_n = \frac1L\int_{-L}^{L} f(x)\cos\frac{n\pi x}{L}\,dx \qquad b_n = \frac1L\int_{-L}^{L} f(x)\sin\frac{n\pi x}{L}\,dx\]
