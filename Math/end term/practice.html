Лаплас

Сдвиг по s и произведение sin·cos
тренировка
Условие
1) \(\mathcal{L}\,[e^{-2t}\cos 4t]\)    2) \(\mathcal{L}\,[\sin 3t\cdot\cos t]\)

Подсказка: формулы 6, 10 и тригонометрическая 1: \(2\sin A\cos B = \sin(A+B) + \sin(A-B)\).

Показать решение

1) \(\mathcal{L}\,[e^{-2t}\cos 4t]\)

ШагЧто делаемРезультат
1Вид \(e^{-at}\cos bt\) (формула 10)\(a = 2,\ b = 4\)
2Подставляем\(\dfrac{s+2}{(s+2)^2+16}\)
3Раскрываем знаменатель\(s^2+4s+20\)
Ответ 1\(\dfrac{s+2}{(s+2)^2+16} = \dfrac{s+2}{s^2+4s+20},\quad s > -2\)

2) \(\mathcal{L}\,[\sin 3t\cdot\cos t]\)

ШагЧто делаемРезультат
1Триг. 1, \(A = 3t,\ B = t\)\(\sin 3t\cos t = \tfrac12[\sin 4t + \sin 2t]\)
2Формула 6 для каждого слагаемого\(\tfrac12\left[\dfrac{4}{s^2+16} + \dfrac{2}{s^2+4}\right]\)
3Общий знаменатель\(\tfrac12\cdot\dfrac{4(s^2+4) + 2(s^2+16)}{(s^2+4)(s^2+16)} = \dfrac{3(s^2+8)}{(s^2+4)(s^2+16)}\)
Ответ 2\(\dfrac12\left[\dfrac{4}{s^2+16}+\dfrac{2}{s^2+4}\right] = \dfrac{3(s^2+8)}{(s^2+4)(s^2+16)},\quad s > 0\)

Лаплас — лист в клетку

Осторожно: в пункте 2 появляется отрицательный угол
25 баллов
Условие
1) \(\mathcal{L}\,[e^{-5t}\cos 2t]\)    2) \(\mathcal{L}\,[\sin 2t\cdot\cos 5t]\)
Показать решение

1) \(\mathcal{L}\,[e^{-5t}\cos 2t]\)

ШагЧто делаемРезультат
1Вид \(e^{-at}\cos bt\) (формула 10)\(a = 5,\ b = 2\)
2Подставляем\(\dfrac{s+5}{(s+5)^2+4}\)
3Раскрываем знаменатель\(s^2+10s+29\)
Ответ 1\(\dfrac{s+5}{(s+5)^2+4} = \dfrac{s+5}{s^2+10s+29},\quad s > -5\)

2) \(\mathcal{L}\,[\sin 2t\cdot\cos 5t]\)

ШагЧто делаемРезультат
1Триг. 1, \(A = 2t,\ B = 5t\)\(\tfrac12[\sin 7t + \sin(-3t)]\)
2Синус нечётный: \(\sin(-3t) = -\sin 3t\)\(\tfrac12[\sin 7t - \sin 3t]\)
3Формула 6 для каждого слагаемого\(\tfrac12\left[\dfrac{7}{s^2+49} - \dfrac{3}{s^2+9}\right]\)
4Общий знаменатель\(\tfrac12\cdot\dfrac{7(s^2+9) - 3(s^2+49)}{(s^2+9)(s^2+49)} = \dfrac{2(s^2-21)}{(s^2+9)(s^2+49)}\)
Ответ 2\(\dfrac12\left[\dfrac{7}{s^2+49}-\dfrac{3}{s^2+9}\right] = \dfrac{2(s^2-21)}{(s^2+9)(s^2+49)},\quad s > 0\)

Типичная ошибка — оставить \(+\sin 3t\). Если взять \(A = 5t,\ B = 2t\) с формулой триг. 2 — получится то же самое.
