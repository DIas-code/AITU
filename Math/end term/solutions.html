Ряд Фурье

Кусочная функция, L = 1
25 баллов
Условие
Найти ряд Фурье функции и его сумму, \(L = 1\): \[f(x) = \begin{cases} 0, & -1 < x < -\tfrac12 \\ x - 3, & -\tfrac12 \le x \le \tfrac12 \\ 0, & \tfrac12 < x < 1 \end{cases}\]

0Формулы (L = 1)

\[f(x) \sim \frac{a_0}{2} + \sum_{n=1}^{\infty}\bigl(a_n\cos n\pi x + b_n\sin n\pi x\bigr)\] \[a_0 = \int_{-1}^{1} f(x)\,dx,\qquad a_n = \int_{-1}^{1} f(x)\cos n\pi x\,dx,\qquad b_n = \int_{-1}^{1} f(x)\sin n\pi x\,dx\]
Приём. Вне \([-\tfrac12;\tfrac12]\) функция равна 0 — интегрируем только там. Делим \(x - 3\) на нечётную часть \(x\) и чётную \(-3\): на симметричном отрезке нечётная функция даёт интеграл 0.

1Коэффициенты

Коэф.Что остаётсяРезультат
\(a_0\)\(\int_{-1/2}^{1/2}(x-3)\,dx = 0 - 3\cdot1\)\(a_0 = -3,\ \ \frac{a_0}{2} = -\frac32\)
\(a_n\)\(x\cos n\pi x\) нечётная → 0; остаётся \(-3\int_{-1/2}^{1/2}\cos n\pi x\,dx\)\(a_n = -\dfrac{6\sin(n\pi/2)}{n\pi}\)
\(b_n\)\(-3\sin n\pi x\) нечётная → 0; остаётся \(2\int_{0}^{1/2}x\sin n\pi x\,dx\) (по частям)\(b_n = -\dfrac{\cos(n\pi/2)}{n\pi} + \dfrac{2\sin(n\pi/2)}{n^2\pi^2}\)

По частям: \(\int x\sin kx\,dx = -\dfrac{x\cos kx}{k} + \dfrac{\sin kx}{k^2}\), здесь \(k = n\pi\), пределы \(0\) и \(\tfrac12\), результат умножаем на 2.
