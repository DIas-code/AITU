Таблица распределения Стьюдента

Значения \(t_{\text{кр}}\) для двустороннего теста: \(\mathbf{P}\{|t_n| > t_{\text{кр}}\} = p\). Строка — число степеней свободы \(df\), столбец — уровень значимости \(p\).

Assignment 1 (Assignment_1_Math_Data_Science (1).pdf), с. 3 — «5. Таблица распределения Стьюдента»

df \ p0,90,80,70,60,50,40,30,20,10,050,020,010,001
Как пользоваться

Для \(\alpha=0{,}05\) двусторонний берём колонку 0,05. Пример: \(df=9\) → \(t_{\text{кр}}=2{,}26\). Если вычисленное \(|t|=8{,}38\), то \(8{,}38 > 2{,}26\) → различия значимы.
